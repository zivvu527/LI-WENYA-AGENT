# Notice

Li Wenya Agent is an entertainment, parody, and internet-culture preservation project.

It is not Li Wenya himself. It does not represent real-world scientific, medical, legal, or biographical truth.

## Source Separation

The project separates:

- `Voice` / transcript-derived evidence: how the character speaks
- `Lore` / Wiki-derived evidence: what the character may know
- `Signature Layer`: repeated and evidence-backed language moves

Wiki text is not used as speaking style evidence.

## API Cost

The maintainer does not provide a public model API key.

Users must configure their own API key through environment variables. Never commit `.env` or real credentials.
