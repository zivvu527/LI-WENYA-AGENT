# VOICE PROFILE v0.1 冻结审计

> 冻结日期：2026-08-29
>
> 冻结范围：`corpus/video_001_transcript.md` 到 `corpus/video_010_transcript.md`
>
> Voice 证据来源：仅限李文亚本人原始视频 OCR 字幕稿。Wiki、百科、网友整理、二创和文亚宇宙设定不得进入 Voice 规则。

## 1. 审计结论

当前 Voice 层可以进入下一阶段。十条视频已经覆盖了批判/反驳、科研论述、回应质疑、自我叙述、情绪升级、机构化批判、私信回应等多个状态，核心语言骨架已经稳定。

仍需保留边界：OCR 初版未人工校对；video_002、video_009、video_010 有私信/转述内容；video_007 有屏幕界面 OCR 噪声；video_010 公式、数字和英文符号 OCR 噪声较重。

## 2. 总时长

- 视频实际总时长：约 2:25:47。
- OCR 字幕最后时间戳覆盖：2:25:27。
- 差异原因：每秒抽帧和末尾无字幕会使 OCR 时间戳略短于视频实际时长。

## 3. Patterns 置信度

当前 `analysis/patterns.md` 包含 18 个核心语言模式，另有 1 个安全生成约束。

- HIGH：14 个
- MEDIUM：3 个
- LOW：1 个

LOW 项：
- “假关心 -> 恶意攻击转换”：主要来自 video_002，且有私信朗读污染风险；冻结为低置信度观察，不作为稳定生成规则。

MEDIUM 项：
- “外部干扰 -> 研究/写作受阻”：主要来自 video_007；video_010 只补强“干扰”词场，不足以证明“电脑/写作受阻”是高频模式。
- “重大课题抬升机制”：主要来自 video_006；可作为医学/身体主题下的局部节奏，不外推到全部场景。
- “私信回应 -> 拒绝继续耗时”：由 video_002、video_009、video_010 支持，但私信正文归属风险较高，暂不升为 HIGH。

## 4. 单视频过度泛化检查

已修正：
- “假关心 -> 恶意攻击转换”从 MEDIUM 降为 LOW。
- “设备/电脑问题 -> 干扰写作/发表 -> 阻挡科学研究”在常见句式中标注为 MEDIUM，避免被读成全局高频规律。

保留但限权：
- “外部干扰 -> 研究/写作受阻”仍保留，因为 video_007 明确支持，但不升为 HIGH。
- “重大课题抬升机制”保留 MEDIUM，因为目前主要依赖身体/寿命主题语料。

## 5. 反例与修正

未发现后续视频推翻早期核心规则。后续视频主要是限制和细化：

- video_008 到 video_010 强化了“旧理论/权威/利益/大学机构”框架，而不是推翻早期科研论战结构。
- video_009 和 video_010 让“观察方法/仪器质询”从植物气孔场景中稳定出来。
- video_010 的严重 OCR 噪声限制了公式和数字内容的可用性，因此只采纳结构，不采纳公式细节。

## 6. 可合并 Patterns

存在互相包含关系，但 v0.1 先保留为可检索子模式：

- “机构化批判”
- “利益冲突 -> 平民成果受压制”
- “人民群众作为最终裁判”
- “教育权威 -> 看不起普通人 -> 学生被旧理论蒙蔽”

这些都属于更大的“机构/权威批判”簇。未来写 `SKILL.md` 时应合并成一个总模块，下面挂子规则，避免生成时重复堆叠。

## 7. 语录误写规则检查

未发现把单句经典语录直接写成唯一生成规则的问题。`quotes.md` 已明确：Quotes 只作证据和彩蛋，主要生成机制来自 Patterns。

需要继续注意：
- 带现实人名、学校名、法律/医学判断、威胁性表达的原句只能作为语料证据，不进入可复用生成模板。

## 8. 污染检查

已确认用户此前标记的误归属私信内容、资历类私信句子和公开举证要求句子未进入 Voice 规则。冻结审计文件也不复写这些原句，避免 analysis 层再次污染。

继续隔离：
- 私信/评论/网友说法
- 具体网名、人名、网友梗
- 屏幕界面文字和键盘按键 OCR
- 公式、数字、英文单位 OCR 乱码
- 医学、科学、法律结论的事实性外推

## 9. 状态区分

v0.1 支持以下状态：

- 平静解释：有，但样本较少，常很快转入论战；不单独建强规则。
- 科研论述：HIGH。常嵌入反驳，围绕观察、理论、旧理论、新理论展开。
- 回应质疑：HIGH。常通过“他说/私信/网友说”进入，再要求证据或解释。
- 批判/反驳：HIGH。最稳定状态。
- 自我叙述：HIGH。主要在身体、观察、研究经历中服务于论证。
- 情绪升级：HIGH。通过重复、反问、负面定性、机构化上升实现。

## 10. 冻结规则

从 `VOICE PROFILE v0.1` 开始：

- 修改 Voice Profile 的唯一新证据来源：李文亚本人原始音视频语料。
- Wiki、百科、文本整理、网友总结、二创、文亚宇宙设定只能进入 Lore/Knowledge。
- Knowledge decides WHAT to say.
- Voice decides HOW to say it.
