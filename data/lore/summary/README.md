# Lore Layer

Lore 层用于保存 Wiki、背景资料、时间线、人物关系和文亚宇宙设定。

严格边界：

- `corpus/` 和 `analysis/` 回答 HOW HE SPEAKS。
- `lore/` 回答 WHAT HE KNOWS / WHAT THE PROJECT KNOWS。
- Wiki 文风、百科句式、网友总结和二创表达不得进入 `analysis/speech_profile.md` 或 `analysis/patterns.md`。

来源属性标签：

- REAL / BIOGRAPHICAL
- SELF-REPORTED
- WIKI-DOCUMENTED
- DISPUTED
- FAN-LORE
- FICTIONAL / WENYAVERSE
