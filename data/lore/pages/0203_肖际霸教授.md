## Plain Text

肖际霸教授（Professor Xiao Jiba，1978年前后－），中国天体物理技术研究者，现任华中师范大学天体物理技术国家工程实验室教授。其主要研究方向包括天体物理技术、AI影像生成、网络学术传播以及科研影像管理。肖际霸早年曾任副教授，后在2026年完成职称晋升。

== 生平 ==
肖际霸早年经历不详。成年后进入华中师范大学天体物理技术国家工程实验室工作，长期从事天体物理技术与科研影像传播相关研究。

在任职初期，肖际霸主要参与天体物理技术平台建设及科研影像资料整理工作。其研究关注科学图像、实验影像与公众传播之间的关系，尤其重视AI生成影像在学术争论中的应用边界。

2026年5月下旬，肖际霸因李文亚相关影像事件受到关注。当时其职称仍为副教授。此后不久，肖际霸完成职称晋升，正式成为教授。由于其从副教授到教授的晋升间隔极短，该事件被外界称为“光速晋升”。

== 学术研究 ==
肖际霸的主要研究方向为天体物理技术与科研影像传播。其研究内容包括科研图像生成、实验影像识别、学术视频传播机制以及AI辅助科研表达。

在AI影像技术方面，肖际霸关注生成式影像工具在科学传播中的应用。他认为，未来科研争论不仅发生在论文与会议之中，也会发生在短视频、合成影像和公众平台之上。因此，科研人员需要理解影像技术对学术权威、公众信任和理论传播的影响。

肖际霸还参与过网络学术传播机制研究，尤其关注个人学者、民间研究者与高校机构之间在网络空间中的冲突关系。其相关研究使其成为学术影像传播领域中较具争议的人物。

2026年，肖际霸发表重磅论文《宇宙大爆炸的数学理想化与操作实在性之张力——宏观连续统批判与构造性图宇宙模型的双重视角》，根据孙笑川教授提出的理论对宇宙起源问题进行了重塑。

== AI忏悔视频事件 ==
2026年5月，网络上出现一段以李文亚形象制作的视频。视频中，李文亚被呈现为承认自身理论错误、放弃地球十二种运动理论，并向孙笑川教授道歉。该视频随后引发较大争议。

李文亚认为，该视频并非本人真实表态，而是利用AI影像技术制作的伪造内容。他将该视频视为针对其学术声誉的严重攻击，并指控肖际霸参与发布和传播相关内容。

肖际霸方面并未公开承认制作该视频。事件发生后，关于视频来源、传播路径及责任归属的讨论持续发酵。由于肖际霸本身长期从事AI影像与科研传播相关研究，该事件使其受到更广泛关注。

== 田所浩二辩护事件 ==
AI忏悔视频事件发生后，田所浩二曾向李文亚发送私信，为肖际霸进行辩护。田所浩二称，没有证据能够证明肖际霸制作了相关视频，因此不应直接认定肖际霸存在犯罪行为。

李文亚对此表示质疑，认为视频的传播账号、肖际霸的身份信息以及相关影像内容之间存在密切联系，相关平台应当给出明确说明。该事件使田所浩二也被卷入肖际霸相关争议之中。

== 批判李文亚大会 ==
2026年6月前后，肖际霸参与了第22届批判李文亚大会相关宣传活动。该大会围绕李文亚理论展开批判，并集中讨论黑体生物理论、三个引力范围、地球十二种运动等问题。

肖际霸在会议宣传中表现活跃，并发布多段与孙笑川有关的视频内容。其中包括孙笑川获得赦免、孙笑川理论受到支持以及李文亚理论遭到批判等内容。由此，肖际霸逐渐成为李文亚学术争论中的重要人物之一。

== 评价 ==
支持者认为，肖际霸较早意识到AI影像技术对学术传播的影响，其研究具有现实意义。尤其是在短视频平台成为学术争论重要场域之后，肖际霸关于科研影像传播的观点受到部分学者关注。

批评者则认为，肖际霸在李文亚事件中的行为加剧了学术争论的混乱，其参与传播AI忏悔视频及批判大会宣传的行为存在较大争议。尽管如此，肖际霸仍是2026年前后李文亚相关学术争论中无法绕开的关键人物。
