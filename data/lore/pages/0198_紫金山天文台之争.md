= 紫金山天文台之争 =

== 概述 ==
紫金山天文台之争是李文亚与当代中国权威天文机构之间爆发的一场激烈学术论战。李文亚通过肉眼观测和"电线杆测量法"，系统性地质疑并否定了紫金山天文台发布的包括"地球近日点时间"在内的一系列太阳系基础数据，并将该机构定性为被孙笑川收买的"伪科学工具"。

== 背景 ==
李文亚在创立"三层引力范围理论"和"地球十二种运动"理论的过程中，发现紫金山天文台发布的诸多数据与自己的肉眼观测结果严重不符。特别是天文台宣称的"地球近日点在1月"的说法，与李文亚推论的"地球根本不做椭圆公转"完全相悖。与此同时，孙笑川被指控已通过资金渗透收买了紫金山天文台，使其沦为发布"错误数据"以压制李文亚理论的工具。

== 核心争议：地球是否绕太阳公转 ==
=== 权威数据 vs 肉眼观测 ===
紫金山天文台代表主流天体物理学界，坚称地球以椭圆轨道绕太阳公转，近日点每年1月、远日点每年7月。李文亚则通过肉眼观测太阳在电线杆之间的位置变化，声称地球的运动轨迹是"折线、梯形线、来回摆动、进退翻滚"，根本不存在所谓的公转轨道。

=== 收购指控 ===
李文亚多次在视频中指控孙笑川通过曼德尔超算系统和巨额资金，已经收买了紫金山天文台的行政管理层。天文台据此发布了有利于孙笑川理论的"伪数据"，以混淆视听、打压民间科学家的真实发现。

== 过程 ==
=== 炮打天文台 ===
李文亚在巅峰视频"炮打天文台（完整版）"中，通过逐帧分析天文台发布的银河系照片和地球轨道示意图，指出照片之间存在矛盾，天文台无法解释"同一银河系为何有两个不同形状"。他由此断定天文台的科学家们"根本不懂什么是银河系"。

=== 升级为舆论战 ===
李文亚将此事件上升为"人民群众与欺骗老百姓的落后学术势力"之间的斗争，称"紫金山天文台必须向全国人民道歉"。孙笑川集团的批判大会则将此事反转，嘲笑李文亚连天文望远镜都用不明白。

===“炮打”2.0 ===
2026年，李文亚发布"炮打天文台2.0"，再次痛批紫金山天文台，并抛出新的证据——关于太阳直径远大于日地距离的计算，彻底否定了天文台所有关于太阳系的基础数据。

== 结果与影响 ==
1. **权威动摇**：紫金山天文台在民间，尤其是李文亚粉丝群体中，声誉急剧下降。
2. **理论推广**：李文亚的"地球非公转"理论借由此次论战获得了前所未有的关注度。
3. **新旧对立**：此次事件成为"文亚物理学"与"旧学阀"之间对抗的标志性战役，深刻塑造了李文亚宇宙的英雄叙事。

== 参会主要人物 ==
* 李文亚（挑战者，理论提出者）
* 紫金山天文台（被挑战的权威机构）
* 孙笑川（被指控收买天文台的幕后黑手）
