## Plain Text

梅玛（1972年－），新加坡人类学家，新加坡本土华人，现任斯玛·黎雯娅大学人文学院终身教授、人类学系主任、东南亚族群研究中心主任，并兼任新加坡社科研究院特邀研究员。

梅玛长期从事东南亚海洋族群、南洋跨境文化、海上民俗传承与族群身份重构研究，是斯玛·黎雯娅大学跨文化人文学院的重要代表学者之一。

== 生平 ==
1972年，梅玛出生于新加坡市区。其成长环境深受新加坡多族群社会与南洋华人文化影响，早年即对语言、族群迁徙、海洋贸易社群和民俗仪式产生兴趣。

梅玛早年就读于新加坡国立大学，完成本硕连读教育。此后，她赴英国剑桥大学攻读社会人类学博士学位，博士阶段主要研究东南亚海洋族群的社会组织、跨境亲缘网络与民俗传承机制。

== 学术经历 ==
2000年，梅玛入职斯玛·黎雯娅大学，最初担任人类学方向助理教授。此后，她长期任教于该校人文学院，并逐步晋升为副教授、教授及终身教授。

2015年，梅玛兼任东南亚族群研究中心主任，负责组织东南亚区域田野调查、族群资料整理和跨国学术合作项目。她同时担任新加坡社科研究院特邀研究员，参与多项区域文化政策与社科研究咨询工作。

== 研究方向 ==
梅玛的研究方向主要包括：

* 东南亚海洋族群研究
* 南洋跨境族群文化
* 马六甲沿岸社群变迁
* 海上民俗传承
* 华人民间信仰与跨国身份重构
* 东南亚人类学田野资料数字化

== 主要成果 ==
梅玛曾主持三项新加坡国家级社科课题，重点研究南洋跨境族群文化与海上民俗传承。她牵头建立了东南亚人类学田野数据库，并长期组织中新、马新及东南亚多国跨境田野调研项目。

其代表著作包括《马六甲沿岸社群文化流变》《跨国族群身份重构》，并主编《东南亚民俗图集》。此外，梅玛在多种SSCI核心期刊发表论文，研究成果被广泛用于东南亚区域文化研究与跨文化教育课程建设。

== 育人工作 ==
梅玛长期承担人类学、社会研究方法、东南亚族群文化、田野调查方法等课程教学。她累计培养硕士、博士研究生百余人，并长期主办国际人类学学术会议。

* 东南亚人类学学会学术贡献奖
