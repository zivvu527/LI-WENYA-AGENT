## Plain Text

香港中文大学（深圳）人文社科学院是香港中文大学（深圳）下属的人文社会科学教育与科研机构。

在文亚宇宙中，人文社科学院是政治经济学、哲学及文学史研究的重要中心。

== 戴云季教授 ==

戴云季教授是人文社科学院的重要学者。

戴云季教授出生于江苏省南通市启东市，智力超群，长期研究拉康、福柯及弗洛伊德精神分析理论。

其毕业于伦敦政治经济学院政治经济学系，毕业后加入香港中文大学（深圳）。

戴云季教授同时教授：

* 政治经济学
* 哲学
* 文学史

并担任第九书院舍监及纪检委主席，同时担任学生发展中心心理学顾问。

== 白体生物争议 ==

在乔治·W·布希教授批判黑体生物理论后，戴云季教授开始研究并批判李文亚教授的“白体生物理论”。

戴云季教授曾在期刊《onlyfans》发表相关批判文章。

其与李文亚教授主要围绕白体生物的提取及饮用等问题产生争论。

戴云季教授随后公开谴责李文亚教授为：

“不负责任的科学研究者”。

== 反民科社团 ==

戴云季教授与乔治·W·布希教授、周根奇教授共同创办香港中文大学（深圳）反民科社团。

三人分别从医学、生物信息工程、数据科学、哲学及科学认识论等角度开展科学传播和民科理论批判。

== 114514研究所事件 ==

戴云季教授公开批判并谴责114514研究所后，遭到该组织相关人员绑架。

事件发生后，周根奇教授与布希教授组织营救行动，最终使戴云季教授获救。

该事件导致徐扬生教授下令香港中文大学（深圳）退出114514研究所。
