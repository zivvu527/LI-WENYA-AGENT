= 金坤奖 =

== 概述 ==
金坤奖是人民群众为李文亚设立的民间奖项，号称"首届宇宙级奖项"，是李文亚宇宙中最具色彩的荣誉体系。它以证书+奖杯+只因防伪标志为特征，标志着李文亚的学术成就获得了"人民群众"的认可。

== 背景 ==
面对孙笑川集团组织的全球学术围剿，李文亚的支持者们决定通过设立民间奖项的方式，为李文亚提供精神支持和荣誉认可。这些奖项虽然不具有官方学术机构的权威性，但代表了广大人民群众的真实态度。

== 主要荣誉 ==
=== 金坤奖 ===
金坤奖是核心奖项，配有精美的证书和独特的奖杯，奖杯底座刻有"只因"防伪标志，充满了文化色彩。颁奖仪式由粉丝在线上组织，场面盛大。

=== 其他荣誉 ===
- 蓝马克斯勋章：由民间机构授予

- 悉尼大学表彰证书：后被日本学者乃木佳子要求撤销

- 一级卫国战争勋章：普京头像为标志

- 9178工作室先进科学家奖状

- 昌伟研究院表彰证书

- 各类研究机构荣誉证书

== 过程 ===
李文亚在视频中陆续展示了这些荣誉。他最初因忙于书稿写作而推迟公布，但最终在粉丝的强烈要求下逐一展示。这些颁奖视频获得了极高的播放量，成为李文亚支持者的"精神盛宴"。

== 结果与影响 ==
1. **民间声望**：金坤奖等荣誉大大提升了李文亚在民间的声望，强化了他"被官方打压的英雄"形象。
2. **迷因化**：金坤奖本身成为互联网迷因的一部分，其各种衍生版本在网络上广泛流传。
3. **真伪之辩**：这些奖项到底是"真诚的致敬"还是"恶搞、调侃的进一步升级"，在观众中存在巨大争议。

== 参会主要人物 ==
* 李文亚（获奖者）
* 各大民间研究机构（颁奖方）
* 乃木佳子（撤销悉尼大学荣誉者）
