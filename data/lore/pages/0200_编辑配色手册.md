== <span style="color:var(--wy-heading-1);">六个常用颜色</span> ==
<div style="height:3px;width:64px;background:var(--wy-accent);margin:2px 0 20px;"></div>

<div style="background:var(--wy-bg-soft);border:1px solid var(--wy-border-color);border-radius:10px;padding:20px 26px;margin-bottom:24px;">

</div>

<div style="border-left:3px solid var(--wy-accent);padding:10px 16px;margin-bottom:24px;background:var(--wy-bg-soft);color:var(--wy-text-main);font-size:13px;">
新手只要记住墨蓝和黄铜这两个就够了 —— 标题用墨蓝，分割线/强调用黄铜，其余颜色是进阶用法。
</div>

== <span style="color:var(--wy-heading-1);">场景一：给标题上色</span> ==
<div style="height:3px;width:64px;background:var(--wy-accent);margin:2px 0 20px;"></div>

写条目时二级标题想变成墨蓝色，把 <code>==标题==</code> 换成：

<pre>
== <span style="color:var(--wy-heading-1);">你的标题</span> ==
</pre>

想在标题下加一条黄铜细线（其他页面都有的那种装饰线），标题下面再加一行：

<pre>
<div style="height:3px;width:64px;background:var(--wy-accent);margin:2px 0 20px;"></div>
</pre>

== <span style="color:var(--wy-heading-1);">场景二：加一个提示框</span> ==
<div style="height:3px;width:64px;background:var(--wy-accent);margin:2px 0 20px;"></div>

不用自己写颜色代码，直接用现成的三个模板，改里面的文字就行：

<pre>

</pre>

* 蓝色标题栏 → 用 <code>Template:Info</code>（一般告知）
* 深黄铜标题栏 → 用 <code>Template:Notice</code>（需要注意）
* 红色标题栏 → 用 <code>Template:Warn</code>（警告 / 重要提醒）

详细用法看：提示模板 · 提醒模板 · 警告模板

== <span style="color:var(--wy-heading-1);">场景三：做一张浅色卡片</span> ==
<div style="height:3px;width:64px;background:var(--wy-accent);margin:2px 0 20px;"></div>

想把一段内容装进一个圆角小卡片里（比如首页那种），复制这段，把中间文字换掉：

<pre>
<div style="background:var(--wy-bg-soft);border:1px solid var(--wy-border-color);border-radius:10px;padding:16px 22px;">
这里写你的内容。
</div>
</pre>

== <span style="color:var(--wy-heading-1);">场景四：加一个状态标签</span> ==
<div style="height:3px;width:64px;background:var(--wy-accent);margin:2px 0 20px;"></div>

想在条目里加个小标签，比如"已验证"或"限制访问"：

<pre>
<span style="background:#4A5D45;color:#fff;font-size:10px;padding:2px 8px;border-radius:2px;">已验证</span>
<span style="background:var(--wy-warn);color:#fff;font-size:10px;padding:2px 8px;border-radius:2px;">限制访问</span>
</pre>

效果大概是这样：
<span style="background:#4A5D45;color:#fff;font-size:10px;padding:2px 8px;border-radius:2px;">已验证</span>
<span style="background:var(--wy-warn);color:#fff;font-size:10px;padding:2px 8px;border-radius:2px;">限制访问</span>

== <span style="color:var(--wy-heading-1);">场景五：给链接文字单独上色</span> ==
<div style="height:3px;width:64px;background:var(--wy-accent);margin:2px 0 20px;"></div>

注意： 直接给 <code>链接</code> 外面包颜色是没用的，链接自己的颜色会盖掉。
要把颜色写在链接文字里面：

<pre>
<span style="color:var(--wy-heading-1);">显示的文字</span>
</pre>

== <span style="color:var(--wy-heading-1);">不要用的颜色</span> ==
<div style="height:3px;width:64px;background:var(--wy-accent);margin:2px 0 20px;"></div>

<div style="background:var(--wy-bg-soft);border:1px solid var(--wy-border-color);border-radius:10px;padding:18px 24px;line-height:2;color:var(--wy-text-main);">
以下颜色跟整体风格不搭，编辑时请避免：
* <span style="display:inline-block;width:14px;height:14px;background:#C9D3E8;border-radius:2px;vertical-align:middle;"></span> 浅蓝色边框（<code>#C9D3E8</code> 之类）—— 请用褪色棕 <code>var(--wy-border-color)</code> 代替
* <span style="display:inline-block;width:14px;height:14px;background:#FFCC33;border-radius:2px;vertical-align:middle;"></span> 亮黄色（<code>#FFCC33</code> 之类）—— 太跳脱，需要黄色调时用深黄铜 <code>var(--wy-heading-3)</code>
* <span style="display:inline-block;width:14px;height:14px;background:#B80000;border-radius:2px;vertical-align:middle;"></span> 正红色（<code>#B80000</code> 之类）—— 请用氧化红 <code>var(--wy-warn)</code> 代替，更沉稳
* 纯黑色大字标题 —— 标题请统一用墨蓝 <code>var(--wy-heading-1)</code>
</div>
