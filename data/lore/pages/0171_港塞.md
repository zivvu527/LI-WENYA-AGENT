## Plain Text

港塞（1975年－），华人物理学者，凝聚态物理与量子材料研究者，现任斯玛·黎雯娅大学工科院物理系终身教授、量子材料研究中心主任。

港塞长期从事二维量子材料、半导体微观物理、新型量子器件理论推演与亚太量子物理合作研究，是斯玛·黎雯娅大学工科与基础物理方向的重要学科带头人。

== 生平 ==
1975年，港塞出生于华人家庭。其早年接受系统理工科教育，本科毕业于国内顶尖物理系，后赴新加坡深造。

港塞在新加坡南洋理工大学攻读凝聚态物理博士学位，研究方向集中于低维材料电子结构、半导体微观机制与量子输运现象。博士阶段的训练奠定了其后来在量子材料研究方面的学术基础。

== 学术经历 ==
2005年，港塞入职斯玛·黎雯娅大学，进入工科院物理系任教。其早期主要承担基础物理、固体物理、量子力学和半导体物理课程教学，同时参与学校物理实验平台建设。

2019年，港塞晋升为终身教授，并出任量子材料研究中心主任。此后，他统筹学校量子材料实验室建设，推动斯玛·黎雯娅大学在亚太量子材料研究网络中的合作布局。

== 研究方向 ==
港塞的主要研究方向包括：

* 二维量子材料
* 半导体微观物理
* 凝聚态物理
* 新型量子器件理论推演
* 量子输运与低维电子结构
* 半导体材料应用与器件建模

== 主要成果 ==
港塞主持新加坡科技局重点物理项目，围绕二维量子材料和半导体微观结构展开系统研究。他曾完成多款新型量子器件理论推演，并参与亚太多国量子物理科研合作。

截至2026年，港塞已在顶级物理期刊发表论文70余篇，拥有三项半导体材料发明专利。他长期推动斯玛·黎雯娅大学量子材料实验室建设，使该实验室成为学校工科院的重要科研平台之一。

== 育人工作 ==
港塞长期负责物理系研究生培养工作，指导数十名物理专业硕士、博士研究生。他搭建了高校量子物理特色实验室，并多次举办亚太物理学术论坛，为学校物理学科国际化发展提供支撑。
