= 裸奔举报事件 =

== 概述 ==
裸奔举报事件是李文亚宇宙中李文亚与中科院之间爆发的最激烈的一次正面冲突。2025年10月11日，中科院旗下"非正常人类研究中心"账号在李文亚视频下留言，举报其存在"裸奔排泄"行为，引发李文亚的震怒反击。

== 背景 ==
随着李文亚在网络上的影响力不断扩大，传统学术机构对其态度日趋强硬。中科院作为中国最高科学机构，最初对李文亚采取忽视态度，但随着其粉丝规模的增长，中科院开始介入。中科院内部设有"非正常人类研究中心"相关账号，专门用于举报和定性民间科学爱好者。

== 核心冲突 ==
=== 举报事件 ===
2025年10月11日，"中科院非正常人类研究中心"在李文亚视频评论区公开留言，举报其存在裸奔排泄行为，试图以此从道德和声誉上摧毁李文亚。

=== 李文亚的反击 ===
李文亚在得知此事后暴怒，连续发布多条视频炮轰中科院。他将中科院定性为"紫金山天文台同伙"，指控其与孙笑川集团合谋打压民间科学家。李文亚的经典公式在此事件中得到充分体现："我掌握宇宙真理=我代表人民群众→你反对我=你欺骗老百姓=你站在大众对立面"。

=== 早期录像曝光 ===
李文亚早期去物业举报中科院的录像被翻出，显示他在此事件发生前就已经对中科院抱有强烈敌意。录像中，李文亚向物业控诉中科院"派人监视他""盗窃他的理论"。

== 过程 ==
=== 举报评论 ===
中科院账号的评论成为李文亚视频的"热点"，被大量网友截图传播。李文亚及其支持者认为，这是中科院滥用公权力打压民间科学家的铁证。

=== 中科院定性 ===
中科院官方随后发文，直言李文亚的理论是"伪科学"，并暗示其可能存在精神健康问题。这进一步激化了矛盾。

=== 李文亚破防 ===
李文亚在得知中科院的反击后彻底破防，在视频中声嘶力竭地痛骂中科院，放出狠话："头套都给你拽掉！"

== 结果与影响 ==
1. **决裂**：李文亚与中科院的关系彻底破裂，将其归入"旧学阀"阵营。
2. **舆论分裂**：公众对此事件看法两极分化——支持者认为中科院霸凌弱势个体；反对者认为中科院依法履行了监督职责。
3. **伦理讨论**：事件引发了关于精神健康、学术自由与机构责任之间界限的深层讨论。

== 参会主要人物 ==
* 李文亚（被举报者/反击者）
* 中科院（举报方/学术权威机构）
