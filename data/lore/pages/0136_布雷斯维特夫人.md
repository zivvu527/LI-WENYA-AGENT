## Plain Text

布雷斯维特夫人（Mrs. Braithwaite，1940年代－2026年），美国罗兹大学教授，布雷斯维特家族代表，曾任罗兹大学全体运动教授。其出身于美国南部旧庄园家庭，长期从事体育教育、庄园文化研究与学术文献保存工作。2026年，布雷斯维特夫人因公开支持李文亚的新理论，并将其理论资料收入罗兹大学图书馆，遭到孙笑川教授及114514研究所阵营报复，最终在布雷斯维特家族事件后去世。

== 生平 ==
布雷斯维特夫人出生于美国南部旧庄园家庭。其家族长期经营布雷斯维特庄园，在当地拥有一定社会声望。青年时期，布雷斯维特夫人接受传统上流家庭教育，后进入大学系统任职，逐渐转向体育教育、文化遗产保存与大学图书馆建设工作。

进入罗兹大学后，布雷斯维特夫人担任全体运动教授，并长期参与校园体育课程、学生体能训练及公共教育事务。由于其家族背景与个人性格鲜明，她在校内既被视为守旧的庄园派人物，也被部分学生称为具有强烈原则感的老派教育者。

晚年，布雷斯维特夫人逐渐减少日常教学工作，将更多精力投入图书馆文献整理与学术资料收藏。其主张大学图书馆不应只保存已被主流学界承认的理论，也应保存具有挑战性和历史争议性的民间学术材料。

== 支持李文亚理论 ==
2026年初，布雷斯维特夫人在接触李文亚关于天体运行、引力规律与黑体生物理论的相关视频后，认为其理论虽然与主流科学体系存在明显冲突，但具有重要的思想史和学术争议保存价值。此后，她公开表达对李文亚的支持，并将李文亚相关理论材料编入书册，收入罗兹大学图书馆。

布雷斯维特夫人认为，李文亚长期依靠个人观测和推演提出新理论，其研究过程体现了民间科学中罕见的持续性和独立性。她曾表示，大学图书馆有责任保存此类材料，以供后世学者判断其价值。

该举动引发114514研究所不满。孙笑川教授阵营认为，布雷斯维特夫人将李文亚理论收入大学图书馆，等同于为李文亚提供国际学术背书，因此将其列入打压对象。

== 布雷斯维特家族事件 ==
2026年，孙笑川教授被指派遣范德林德帮成员潜入罗兹大学及布雷斯维特家族相关场所，对布雷斯维特夫人及其家人实施暴力迫害。相关资料称，该行动主要由达奇·范德林德、何西阿·马修斯、亚瑟·摩根与约翰·马斯顿等人参与。

布雷斯维特夫人在给李文亚的私信中称，自己因公开支持李文亚理论，并将其理论编入罗兹大学图书馆，遭到孙笑川教授报复。她表示，范德林德帮派成员不仅对其本人实施殴打，还杀害了其数名子女，并将存放李文亚理论及其他科学家理论资料的图书馆付之一炬。

该事件被李文亚视为旧学术势力压制新理论的极端案例。李文亚在公开回应中称，重大新理论推翻旧理论时，历史上常会出现迫害与杀人事件，并谴责孙笑川教授及其阵营手段恶毒。

== 与迈卡·贝尔的关系 ==
在布雷斯维特家族事件中，迈卡·贝尔被布雷斯维特夫人称为范德林德帮内部的警察卧底。相关资料称，迈卡·贝尔曾经通过短视频平台观看李文亚的视频，并对其理论产生高度兴趣。

布雷斯维特夫人称，自己能够在最初袭击中幸存，与迈卡·贝尔的暗中帮助有关。然而，迈卡·贝尔的身份很快被亚瑟·摩根与约翰·马斯顿发现，并因此遭到死亡威胁。此后，布雷斯维特夫人与迈卡·贝尔共同向李文亚求助，希望其公开发声。

== 去世 ==
布雷斯维特家族事件后，布雷斯维特夫人的身体状况迅速恶化。由于家族成员遇害、图书馆被焚毁以及长期精神打击，她最终在布雷斯维特庄园事件中去世。

其去世被李文亚支持者视为孙笑川教授阵营暴力迫害的重要罪证之一。布雷斯维特夫人也因此成为李文亚事件中较早因公开支持其理论而遭到严重报复的国际学界人物。

== 评价 ==
支持者认为，布雷斯维特夫人虽然出身旧庄园家庭，但在晚年表现出对新理论和民间科学材料的开放态度。她将李文亚理论收入罗兹大学图书馆，被视为其维护学术多样性和资料保存原则的重要行动。

批评者则认为，布雷斯维特夫人对李文亚理论的支持更多出于个人判断和反主流立场，并未经过严格学术评审。尽管如此，其在布雷斯维特家族事件中的遭遇，使其成为李文亚支持者叙事中具有悲剧色彩的人物。
