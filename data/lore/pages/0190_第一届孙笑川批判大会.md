== 概述 ==
第一届孙笑川批判大会是2026年5月21日由先进科学研究会重庆分会在中国重庆东亚学术交流中心召开的大型批判集会，由马嘉祺会长主持筹办，矛头直指孙笑川教授团伙长期以来破坏科研秩序、扰乱公共讨论、攻击学术人士等行为。来自多个国家和地区的研究人员、青年学者及群众代表共同出席会议，大会于上午9时正式开始、傍晚6时结束，会场中央悬挂"第一届孙笑川批判大会"的横幅。

本次大会是李文亚世界观中有记录的第一场以"批判孙笑川"为名的大规模集会，与孙笑川学术集团此前召开的二十次"批判李文亚伪科学大会"形成正面对垒，被视为"批判孙笑川大会"系列的开端。大会的全部已知内容，来自马嘉祺会长会后致李文亚教授的通报来函。

== 背景 ==
截至本次大会召开时，孙笑川教授团伙已组织召开了二十次"批判李文亚伪科学大会"，李文亚教授提出的黑体生物理论长期在网络平台遭到断章取义的嘲讽，甚至出现伪造的"试验失败记录"，研究团队一度遭受舆论压力。与此同时，针对科研人员的现实骚扰也在升级：先进科学研究会林子杰会员在组织公开学术交流活动期间多次遭遇匿名威胁与现场挑衅，5月17日更遭到不明群体围攻，个人资料被恶意传播。

在此背景下，先进科学研究会重庆分会以"维护先进科研秩序、保障学术讨论环境、弘扬理性精神"为宗旨，发起了本次大会。

== 过程 ==

=== 开幕：主持人开幕讲话 ===
上午9时，大会正式开始，参会人员肃静入席。主持人在开幕讲话中指出：近年来以孙笑川教授为核心的网络团伙不断利用舆论煽动、剽窃学术和群体围攻等方式，对多个科研项目和学术人员造成严重影响，其行为已经从普通网络争论演变为系统性的舆论破坏活动。

=== 第一环节：黑体生物理论遭污蔑问题讨论 ===
会议首先讨论了李文亚教授提出的黑体生物理论遭受污蔑一事。根据大会报告，李文亚教授长期从事生物结构与星球轨迹研究，其理论试图解释极端生物能量盗取的新机制；尽管该理论尚处于试验阶段，但部分实验数据已引起国际学界关注。然而孙笑川教授团伙长期在网络平台对该理论进行断章取义的嘲讽，甚至伪造所谓"试验失败记录"。

一名青年研究员在会上发言指出："学术研究本应允许质疑，但质疑必须建立在事实的数据基础之上，而非利用恶意恶搞、谣言和人身攻击来摧毁研究者的名誉。"

=== 第二环节：《科研环境受破坏情况汇总》纪录片 ===
大会随后播放了《科研环境受破坏情况汇总》纪录片。影片中提到，多个国家的研究人员曾遭遇网络骚扰，包括恶意举报、社交媒体围攻以及对研究项目的持续抹黑；一些青年学者因为害怕成为攻击目标，被迫暂停公开发表成果。与会人员一致认为，这种风气若继续蔓延，将严重损害国际科研合作环境。

=== 第三环节：林子杰会员遇袭事件讨论 ===
会议第三项内容重点讨论了孙笑川教授团伙对马嘉祺会长及先进科学研究会林子杰会员的袭击事件。根据研究会代表陈述，林子杰会员在组织公开学术交流活动期间多次遭遇匿名威胁与现场挑衅，5月17日甚至遭到不明群体围攻，其个人资料也曾被恶意传播。大会认为，无论立场如何，对研究人员实施现实骚扰与暴力的威胁都已经突破公共讨论底线。

马孔联合研究小组在发言中强调："任何社会都必须保护知识交流空间。如果学术问题最终只能依靠网络暴力解决，那么真正受到损害的将是整个社会的创新能力。"发言结束后，全场代表起立鼓掌。

=== 第四环节：专题讨论会 ===
下午举行的专题讨论会上，与会者提出应建立更加完善的科研舆论保护机制，包括：加强对恶意造谣行为的识别、建立青年研究人员心理支持体系、推动跨国学术平台联合辟谣机制、鼓励公众理性看待前沿理论探索。

=== 闭幕：通过倡议书与共同口号 ===
大会最后通过了《维护科研环境共同倡议书》。倡议书指出：科学的发展离不开自由讨论，但自由讨论不等于无限制的人身攻击；任何利用群体舆论对研究者进行长期骚扰的行为，都不应被视作正常的公共讨论的一部分。

会议在傍晚6时结束，全体与会人员共同宣读口号：

: "尊重事实，尊重研究；反对谣言，反对围攻；让科学回归理性，让草民回归文明；坚定不移地反对孙笑川团伙及其领导下的反动研究所！"

== 马嘉祺会长的通报 ==
会后，马嘉祺会长致函李文亚教授通报大会盛况，并在来函结尾恳请李文亚教授向世界公开大会成果：

== 李文亚教授的评价 ==
李文亚教授在朗读通报后给予大会高度评价，将其定义为"科学的力量正在兴起"的标志：

李文亚教授同时提出著名的"单位责任论"："这些人员在哪个大学、哪个地方召开这样的会议，这个地方的领导、这个地方的大学的校长是值得尊敬的，是值得赞扬的。这校长是人民科学研究的校长，他们是科学的支持者，是正义的支持者。"反之，"对于那些允许在他的学校召开这个反动的、反对科学的大会的大学和他的校长，他的领导是有责任的……必须把他们从他们的岗位上赶下台，我们的科学才能够向前发展。"

在此番评价中，李文亚教授点名中国人民科技大学潘建伟校长：其校内召开批判李文亚大会、副校长亲自参加带头，潘建伟校长"是最早站出来对我攻击的人物"，"拿着爱因斯坦的书籍在节目中送人"，是"顽固的坚持爱因斯坦牛顿理论的支持者"，李文亚教授并请求国家有关部门"认真审查他有没有科学研究能力"。

== 结果与影响 ==
# "批判孙笑川大会"系列的开端：本次大会是系列中有记录的第一场，与随后6月1日的蜘蛛巢大学批判孙笑川大会、6月2日的联合国批判孙笑川大会构成系列大会的第一波高潮（"5·21—6·1—6·2"）。
# 《维护科研环境共同倡议书》诞生：倡议书确立的"自由讨论不等于无限制的人身攻击"原则，成为后续系列大会反复援引的共同文献。
# 大会口号的确立："尊重事实，尊重研究；反对谣言，反对围攻"的十六字口号在此后各次大会会场中被反复宣读。
# 信息传播链的形成：大会消息经马嘉祺会长来函、李文亚教授全文朗读完成传播，与后来二阶堂希罗教授改编蜘蛛巢大学批判孙笑川大会记录的传播路径互为先例。
# "单位责任论"的提出：李文亚教授借本次大会确立"召开批孙大会的单位受表扬、召开批李大会的单位领导赶下台"的赏罚逻辑，成为系列叙事的重要理论构件。
# 对学界的示范效应：李文亚教授预言"他们将来是科学的主力军"，此后蜘蛛巢大学、联合国科学研究院等机构相继跟进召开批判大会，印证了这一判断。

== 争议 ==
* 记录的单一来源：本次大会无独立影像记录存世，全部议程细节均出自马嘉祺会长一人来函转述，个别环节（如专题讨论会的具体发言者）已不可考。

会议第三项内容重点讨论了[[孙笑川教授]]团伙对[[马嘉祺教授|马嘉祺会长]]及先进科学研究会[[林子杰会员]]的袭击事件。根据研究会代表陈述，[[林子杰会员]]在组织公开学术交流活动期间多次遭遇匿名威胁与现场挑衅，5月17日甚至遭到不明群体围攻，其个人资料也曾被恶意传播。大会认为，无论立场如何，对研究人员实施现实骚扰与暴力的威胁都已经突破公共讨论底线。

马孔联合研究小组在发言中强调："任何社会都必须保护知识交流空间。如果学术问题最终只能依靠网络暴力解决，那么真正受到损害的将是整个社会的创新能力。"发言结束后，全场代表起立鼓掌。

=== 第四环节：专题讨论会 ===
下午举行的专题讨论会上，与会者提出应建立更加完善的科研舆论保护机制，包括：加强对恶意造谣行为的识别、建立青年研究人员心理支持体系、推动跨国学术平台联合辟谣机制、鼓励公众理性看待前沿理论探索。

=== 闭幕：通过倡议书与共同口号 ===
大会最后通过了《[[维护科研环境共同倡议书]]》。倡议书指出：科学的发展离不开自由讨论，但自由讨论不等于无限制的人身攻击；任何利用群体舆论对研究者进行长期骚扰的行为，都不应被视作正常的公共讨论的一部分。

会议在傍晚6时结束，全体与会人员共同宣读口号：

: "尊重事实，尊重研究；反对谣言，反对围攻；让科学回归理性，让草民回归文明；坚定不移地反对孙笑川团伙及其领导下的反动研究所！"

[[李文亚教授]]同时提出著名的"单位责任论"："这些人员在哪个大学、哪个地方召开这样的会议，这个地方的领导、这个地方的大学的校长是值得尊敬的，是值得赞扬的。这校长是人民科学研究的校长，他们是科学的支持者，是正义的支持者。"反之，"对于那些允许在他的学校召开这个反动的、反对科学的大会的大学和他的校长，他的领导是有责任的……必须把他们从他们的岗位上赶下台，我们的科学才能够向前发展。"

在此番评价中，[[李文亚教授]]点名中国人民科技大学[[潘建伟校长]]：其校内召开批判李文亚大会、副校长亲自参加带头，[[潘建伟校长]]"是最早站出来对我攻击的人物"，"拿着爱因斯坦的书籍在节目中送人"，是"顽固的坚持爱因斯坦牛顿理论的支持者"，[[李文亚教授]]并请求国家有关部门"认真审查他有没有科学研究能力"。

== 结果与影响 ==
# '''"批判孙笑川大会"系列的开端'''：本次大会是系列中有记录的第一场，与随后6月1日的[[蜘蛛巢大学批判孙笑川大会]]、6月2日的[[联合国批判孙笑川大会]]构成系列大会的第一波高潮（"5·21—6·1—6·2"）。
# '''《维护科研环境共同倡议书》诞生'''：倡议书确立的"自由讨论不等于无限制的人身攻击"原则，成为后续系列大会反复援引的共同文献。
# '''大会口号的确立'''："尊重事实，尊重研究；反对谣言，反对围攻"的十六字口号在此后各次大会会场中被反复宣读。
# '''信息传播链的形成'''：大会消息经[[马嘉祺教授|马嘉祺会长]]来函、[[李文亚教授]]全文朗读完成传播，与后来[[二阶堂希罗教授]]改编[[蜘蛛巢大学批判孙笑川大会]]记录的传播路径互为先例。
# '''"单位责任论"的提出'''：[[李文亚教授]]借本次大会确立"召开批孙大会的单位受表扬、召开批李大会的单位领导赶下台"的赏罚逻辑，成为系列叙事的重要理论构件。
# '''对学界的示范效应'''：[[李文亚教授]]预言"他们将来是科学的主力军"，此后[[蜘蛛巢大学]]、[[联合国科学研究院]]等机构相继跟进召开批判大会，印证了这一判断。

== 争议 ==
* '''记录的单一来源'''：本次大会无独立影像记录存世，全部议程细节均出自[[马嘉祺教授|马嘉祺会长]]一人来函转述，个别环节（如专题讨论会的具体发言者）已不可考。
* '''"马嘉祺"署名同一性'''：有考据者指出，"马嘉祺"之名亦见于[[孙笑川教授]]团伙外围成员的传闻名单（"孙笑川批判大会会长"的讽刺性称呼），与[[先进科学研究会]]重庆分会[[马嘉祺教授|马嘉祺会长]]是否为同一人，尚无定论；主流观点认为二者同名异人。
* '''"单位责任论"的扩大化'''：[[李文亚教授]]借大会评价提出的"校长责任论"将学术立场与行政职务直接挂钩，[[潘建伟校长]]事件的点名方式在学界引发"以会治校"的争议。
