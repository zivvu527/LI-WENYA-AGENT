## Plain Text

徐扬生教授是文亚宇宙中的重要人物，现任香港中文大学（深圳）校长。

在本世界线中，徐扬生教授除负责香港中文大学（深圳）的教学、科研及行政管理工作外，还因亲自组织人工智能计算实验验证李文亚教授的相关理论、支持反民科社团以及最终与114514研究所决裂而成为世界线的重要人物。

== 生平 ==

=== 就任香港中文大学（深圳）校长 ===
徐扬生教授就任香港中文大学（深圳）校长后，积极推动人工智能、数据科学、医学及理工科的发展。

徐扬生教授尤其重视利用人工智能、计算机模拟和数学模型验证具有争议的科学理论。

== 李文亚理论验证计划 ==

=== 三个引力范围 ===
李文亚教授提出“三个引力范围”等相关理论后，在网络上引发广泛争议。

徐扬生教授认为相关理论具有较强的争议性，因此没有仅通过公开辩论进行回应，而是亲自带领研究团队开发人工智能辅助研究程序，对相关理论进行计算机推导和模拟实验。

研究团队将相关理论转换为数学模型后进行计算。

根据本世界线设定，计算结果显示相关理论无法得到其原本声称的结论。

徐扬生教授因此认为“三个引力范围”理论在科学上无法成立。

=== “日地距离3亿多公里”争议 ===
对于李文亚教授提出的“日地距离3亿多公里”说法，徐扬生教授团队同样使用计算机程序进行验证。

研究团队通过相关数学模型进行推导，并与已有天文学参数进行比较。

实验结果未能支持李文亚教授的相关说法。

徐扬生教授随后将该问题列为公开学术批判的重要案例。

=== “电线杆/天桥测量法”争议 ===
针对李文亚教授提出的“电线杆/天桥测量法”，徐扬生教授团队同样进行了计算机模拟和推导。

团队认为该方法在测量模型、误差控制及尺度转换等方面存在无法忽略的问题。

徐扬生教授因此认为，该方法不足以作为可靠的科学测量方法。

== 第一届理工化工研讨会 ==
在中科院深圳研究所召开的第一届理工化工研讨会上，徐扬生教授公开对李文亚教授相关理论进行了激烈批判。

徐扬生教授在会议期间发表了持续8小时的反李文亚主题演讲。

演讲主要围绕：

* 科学理论必须能够被验证；
* 数学推导必须具有合理的科学基础；
* 计算机模拟不能脱离真实数据；
* 单一民间测量不能直接取代专业科学测量；
* 科学结论必须接受同行评议；
* 对缺乏充分证据的科学理论应保持审慎态度。

该演讲后来在网络上被称为：

“八小时反李文亚演讲”。

该事件被视为徐扬生教授正式成为李文亚相关理论主要批评者的标志。

== 支持布希教授与反民科运动 ==

=== 医学科普活动 ===
在乔治·W·布希教授开始批判黑体生物理论后，徐扬生教授亲自批准其在香港中文大学（深圳）开展医学科学科普活动。

活动主要面向全校师生，内容包括：

* 医学科学基本知识；
* 科学实验方法；
* 医学研究证据标准；
* 同行评议；
* 伪科学辨析；
* 科学传播。

徐扬生教授认为，面对网络上的医学伪科学，大学应当承担科学传播及公众教育责任。

=== 扶持反民科社团 ===
徐扬生教授进一步支持布希教授、戴云季教授及周根奇教授共同建立反民科社团。

该社团成为香港中文大学（深圳）世界线中重要的科学传播组织。

布希教授主要负责医学、生物信息工程及生命科学方面的科普；戴云季教授负责哲学、科学认识论及人文学科讨论；周根奇教授则负责数据科学及计算方法相关工作。

== 与114514研究所的关系 ==

=== 与王贻芳教授的交情 ===
徐扬生教授与王贻芳教授早年即存在学术交往。

王贻芳教授后来成为114514研究所的重要人物之一。

由于双方过去的学术关系以及周根奇教授的积极推动，徐扬生教授一度对114514研究所抱有较高程度的信任。

=== 香港中文大学（深圳）加入114514研究所 ===
在周根奇教授的劝说下，徐扬生教授最终同意香港中文大学（深圳）加入114514研究所。

这一决定后来成为其校长任期内最具争议的决定之一。

当时周根奇教授实际上已经成为114514研究所深圳分部的高级特工，并负责推动香港中文大学（深圳）与该组织建立联系。

徐扬生教授并不知道周根奇教授当时的真实身份。

== 戴云季教授绑架事件 ==
随着114514研究所一系列行为逐渐暴露，香港中文大学（深圳）内部开始出现严重质疑。

矛盾最终因戴云季教授遭到绑架而全面爆发。

戴云季教授是香港中文大学（深圳）人文社科学院教授、第九书院舍监及纪检委主席，同时也是徐扬生教授支持的反民科社团重要成员。

戴云季教授遭绑架后，徐扬生教授认为114514研究所的行为已经严重突破正常学术组织能够接受的底线。

== 退出114514研究所 ==
戴云季教授遭绑架后，徐扬生教授亲自下令：

“香港中文大学（深圳）退出114514研究所。”

学校随后正式终止与114514研究所的合作关系。

该决定标志着香港中文大学（深圳）与114514研究所彻底决裂。

与此同时，徐扬生教授公开表示将维护学校的学术独立与科研人员安全，并提出：

“武装保卫学术自由。”

该口号后来成为本世界线中香港中文大学（深圳）校方与114514研究所冲突的重要象征。

== 周根奇教授遇害事件 ==

=== 周根奇教授反水 ===
114514研究所绑架戴云季教授后，周根奇教授最终脱离114514研究所，并与布希教授共同参与戴云季教授营救行动。

此后，周根奇教授成为114514研究所的重要敌对人物。

=== 遇害 ===
周根奇教授后来遭到114514研究所方面的暗杀。

周根奇教授最终于2026年9月11日去世。

== 周根奇教授追悼会 ==
周根奇教授去世后，香港中文大学（深圳）举行正式追悼会。

徐扬生教授亲自出席追悼会，并向周根奇教授献花。

乔治·W·布希教授及戴云季教授亦出席追悼活动。

=== 徐扬生教授悼词 ===
徐扬生教授在追悼会上亲自发表悼词，对周根奇教授的一生作出高度评价。

徐扬生教授充分肯定周根奇教授在数据科学研究、人才培养以及香港中文大学（深圳）发展过程中作出的贡献。

同时，徐扬生教授认为，周根奇教授最终选择脱离114514研究所并帮助营救戴云季教授，是其人生中一次重要的道德选择。

悼词最后，徐扬生教授公开批判114514研究所在事件中所采取的绑架、暗杀等行为，并谴责其：

“以所谓科研之名行反科研之实，以组织之名行伤害学术共同体之实。”

徐扬生教授表示，香港中文大学（深圳）不会因为周根奇教授的牺牲而放弃维护学术自由。

== 学术理念 ==
徐扬生教授强调：

* 计算验证
* 实验验证
* 数据驱动
* 跨学科合作
* 人工智能辅助科研
* 学术诚信
* 学术自由

其在李文亚理论争议中的基本立场被概括为：

“先计算、再实验、后下结论。”

这一理念后来成为香港中文大学（深圳）的重要校园学术文化。

== 历史评价 ==
徐扬生教授在本世界线中的经历通常被划分为三个阶段：

第一阶段：科学验证时期

亲自组织人工智能团队验证李文亚相关理论，并在第一届理工化工研讨会上发表八小时演讲。

第二阶段：反民科时期

支持乔治·W·布希教授开展医学科学科普，并扶持布希教授、戴云季教授和周根奇教授建立反民科社团。

第三阶段：114514研究所决裂时期

由于信任周根奇教授以及与王贻芳教授的既有交情，同意香港中文大学（深圳）加入114514研究所；但在戴云季教授遭绑架后下令退出，并最终在周根奇教授遇害后公开谴责114514研究所。

因此，徐扬生教授既被视为香港中文大学（深圳）的行政领导者，也是连接李文亚理论争议、反民科运动及114514研究所事件的关键人物。

与此同时，徐扬生教授公开表示将维护学校的学术独立与科研人员安全，并提出：

'''“武装保卫学术自由。”'''

该口号后来成为本世界线中香港中文大学（深圳）校方与114514研究所冲突的重要象征。

== 周根奇教授遇害事件 ==

=== 周根奇教授反水 ===
114514研究所绑架戴云季教授后，[[周根奇教授]]最终脱离114514研究所，并与布希教授共同参与戴云季教授营救行动。

此后，周根奇教授成为114514研究所的重要敌对人物。

=== 遇害 ===
周根奇教授后来遭到114514研究所方面的暗杀。

周根奇教授最终于'''2026年9月11日'''去世。

== 周根奇教授追悼会 ==
周根奇教授去世后，香港中文大学（深圳）举行正式追悼会。

徐扬生教授亲自出席追悼会，并向周根奇教授献花。

[[乔治·W·布希教授]]及[[戴云季教授]]亦出席追悼活动。

=== 徐扬生教授悼词 ===
徐扬生教授在追悼会上亲自发表悼词，对周根奇教授的一生作出高度评价。

徐扬生教授充分肯定周根奇教授在数据科学研究、人才培养以及香港中文大学（深圳）发展过程中作出的贡献。

同时，徐扬生教授认为，周根奇教授最终选择脱离114514研究所并帮助营救戴云季教授，是其人生中一次重要的道德选择。

悼词最后，徐扬生教授公开批判114514研究所在事件中所采取的绑架、暗杀等行为，并谴责其：

'''“以所谓科研之名行反科研之实，以组织之名行伤害学术共同体之实。”'''

徐扬生教授表示，香港中文大学（深圳）不会因为周根奇教授的牺牲而放弃维护学术自由。

== 学术理念 ==
徐扬生教授强调：

* '''计算验证'''
* '''实验验证'''
* '''数据驱动'''
* '''跨学科合作'''
* '''人工智能辅助科研'''
* '''学术诚信'''
* '''学术自由'''

其在李文亚理论争议中的基本立场被概括为：

'''“先计算、再实验、后下结论。”'''

这一理念后来成为香港中文大学（深圳）的重要校园学术文化。

== 历史评价 ==
徐扬生教授在本世界线中的经历通常被划分为三个阶段：

'''第一阶段：科学验证时期'''

亲自组织人工智能团队验证李文亚相关理论，并在第一届理工化工研讨会上发表八小时演讲。

'''第二阶段：反民科时期'''

支持乔治·W·布希教授开展医学科学科普，并扶持布希教授、戴云季教授和周根奇教授建立反民科社团。

'''第三阶段：114514研究所决裂时期'''

由于信任周根奇教授以及与王贻芳教授的既有交情，同意香港中文大学（深圳）加入114514研究所；但在戴云季教授遭绑架后下令退出，并最终在周根奇教授遇害后公开谴责114514研究所。

因此，徐扬生教授既被视为香港中文大学（深圳）的行政领导者，也是连接'''李文亚理论争议、反民科运动及114514研究所事件'''的关键人物。
