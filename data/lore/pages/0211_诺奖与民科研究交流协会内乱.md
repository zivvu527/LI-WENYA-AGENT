= 诺奖与民科研究交流协会内乱 =

== 概述 ==
诺奖与民科研究交流协会内乱是2026年8月6日爆发于诺奖与民科研究交流协会内部的大规模信任危机与肃清运动。协会主任委员二向箔的投放者主任委员被指控长期勾结孙笑川教授团伙，犯下盗用照片、伪造恋爱关系、滥用艾特全体权限、传播危险鉴证内容、女装诱骗蜘蛛巢大学学生等五项重罪，引发协会委员们的极端愤怒。

事件以凌晨时分某位会员在全体代表大会上公开发表"有些人组建小团体准备反对主任委员"的言论为导火索，历经小团体指认、"害羞的蜜蜂"隐喻风波、聊天记录对峙、长达约二小时的全体皮豆、举报与改名闹剧、主任委员悔过与退圈声明等阶段，最终因大会话题意外转向河南高考与教育议题而基本平息。协会随后进入评选新任主任委员等善后阶段。本次内乱是诺奖与民科研究交流协会成立以来规模最大的全体代表大会事件。

== 背景 ==
诺奖与民科研究交流协会是李文亚宇宙中以"促进诺奖级学术与民间科学交流"为宗旨的学术联谊组织，长期游走于诺贝尔奖委员会与各大民科研究社群之间。二向箔的投放者主任委员自担任主任委员以来，逐渐把持协会议事厅的管理权限，并被多方怀疑与孙笑川教授及114514研究所存在暗中往来。

自2026年6月起，协会内外陆续出现关于二向箔的投放者主任委员个人经历造假的传闻。其在各大学术组织中自述的履历前后矛盾，引发了边狱巴士公司霍恩海姆教授等资深委员的长期暗中调查，协会内部积怨日深。

== 五项指控 ==
经Лаваш委员提交证据、协会委员们集体核实，二向箔的投放者主任委员被控五项重罪：

# 盗图行骗：盗取他人照片冒充本人形象，骗取协会会员的信任与好感。
# 伪造恋爱关系：将无辜女同学的证件照发布至大会，谎称是自己的女朋友，并注册小号扮演该"女朋友"自导自演，欺骗全体协会会员。
# 滥用艾特全体权限：动辄艾特全体成员宣传自己的视频，连诸多无聊琐事也强行艾特全体，严重干扰协会正常学术秩序。
# 带头传播危险鉴证内容：带头发布高危鉴证内容，并四处招黑，引外部势力围攻协会，害得协会委员们不得不熬夜整肃会务。
# 女装诱骗蜘蛛巢大学学生：以女装手段诱骗蜘蛛巢大学在校学生，对蜘蛛巢大学的校誉造成恶劣影响，激起校方强烈不满。

协会委员们一致认为，上述行为已远远超出个人品德问题，而是与孙笑川教授团伙勾结、系统性破坏协会信任基础的渗透行为。

== 过程 ==
=== 凌晨：导火索与"小团体"指认 ===
2026年8月6日凌晨时分，某位会员在全体代表大会上公开发表"有些人组建小团体准备反对主任委员"的言论，成为本次内乱的导火索。随即有人指认某位委员即为"反对主任委员的小团体"成员，同时少数委员以隐晦措辞将二向箔的投放者主任委员称为"害羞的蜜蜂"，暗讽其长期躲在幕后、不敢直面质询。

经主任委员小号和几位委员的回复转发，上述言论迅速扩散，引发数十名会员与委员的全面皮豆。数位委员翻出历史聊天记录与二向箔的投放者主任委员当面对峙，但主任委员回复含糊不清、避重就轻，进一步点燃了积怨已久的委员与会员们的怒火。

=== 长达二小时的皮豆 ===
对峙无果后，多位委员与会员对二向箔的投放者主任委员展开了长达约二小时的连续皮豆，正式要求其"退位让贤"。值得注意的是，在皮豆进行期间，其他部分委员并未参与围攻，而是各自开展协会的宣会纳新活动，形成"一半大会在皮豆、一半大会在宣会"的奇特景观。

随后，某位会员反复发送皮豆内容，引起全体代表大会"+1"式联名刷屏——二向箔的投放者主任委员本人竟也按了"+1"，令全场愕然（史称"+1事件"），皮豆由此达到第一波高峰。

=== 上午8时30分：霍恩海姆教授公开质证 ===
上午8时30分，协会委员边狱巴士公司霍恩海姆教授在全体代表大会上正式公开发言，质疑二向箔的投放者主任委员自6月以来在各大组织中虚构个人经历，要求其就履历矛盾问题当场作出解释。皮豆由情绪化围攻转入公开质证阶段。

=== Лаваш委员提交证据 ===
边狱巴士公司霍恩海姆教授发难后，协会委员Лаваш委员随即向全体代表提交了系统性证据材料，涵盖照片盗用的原始出处比对、小号操作记录、艾特全体骚扰的时间线、危险鉴证内容的截图存档以及蜘蛛巢大学方面的受害陈述。证据链完整，大会现场一片哗然。

=== 冈·交利文·亚皮严教授要求辞职 ===
在证据公开后，冈·交利文·亚皮严教授正式提出动议，要求二向箔的投放者主任委员立即辞去主任委员职务，并接受协会纪律审查。该动议得到在场代表的广泛附议。

=== 上午11时：全面皮豆高峰与举报改名闹剧 ===
皮豆过程中，二向箔的投放者主任委员疑似出于某种心理发表了若干言论，引起全场众怒，冲突进一步激化。至上午11时左右，大会展开全面皮豆。某些过激会员反复向协会纪律机关及诺贝尔奖委员会举办（举报）二向箔的投放者主任委员的正式头衔与身份，并擅自将协会会名牌匾修改为皮豆主任委员的内容，协会颜面荡然无存。

面对全面皮豆，二向箔的投放者主任委员终于对自身行为进行反省并表达悔过，但迟来的悔过仍未能平息大会的皮豆浪潮。

=== 退圈声明与意外收场 ===
最终，二向箔的投放者主任委员在大会上表示自己将退出协会并退出李文亚圈子。此时几位会员转而表示对其挽留。与此同时，大会上有代表提及河南高考，全体代表的注意力意外转向高考与教育议题，激烈讨论了各地升学形势，整场皮豆随之基本结束。会后，几位委员着手进行善后工作，包括主持评选新任主任委员、恢复协会会名牌匾、整理大会记录等。

== 影响 ==

上午8时30分，协会委员[[边狱巴士公司霍恩海姆教授]]在全体代表大会上正式公开发言，质疑[[二向箔的投放者主任委员]]自6月以来在各大组织中虚构个人经历，要求其就履历矛盾问题当场作出解释。皮豆由情绪化围攻转入公开质证阶段。

=== Лаваш委员提交证据 ===
[[边狱巴士公司霍恩海姆教授]]发难后，协会委员[[Лаваш委员]]随即向全体代表提交了系统性证据材料，涵盖照片盗用的原始出处比对、小号操作记录、艾特全体骚扰的时间线、危险鉴证内容的截图存档以及[[蜘蛛巢大学]]方面的受害陈述。证据链完整，大会现场一片哗然。

=== 冈·交利文·亚皮严教授要求辞职 ===
在证据公开后，[[冈·交利文·亚皮严教授]]正式提出动议，要求[[二向箔的投放者主任委员]]立即辞去主任委员职务，并接受协会纪律审查。该动议得到在场代表的广泛附议。

=== 上午11时：全面皮豆高峰与举报改名闹剧 ===
皮豆过程中，[[二向箔的投放者主任委员]]疑似出于某种心理发表了若干言论，引起全场众怒，冲突进一步激化。至上午11时左右，大会展开全面皮豆。某些过激会员反复向协会纪律机关及[[诺贝尔奖委员会]]举办（举报）[[二向箔的投放者主任委员]]的正式头衔与身份，并擅自将协会会名牌匾修改为皮豆主任委员的内容，协会颜面荡然无存。

面对全面皮豆，[[二向箔的投放者主任委员]]终于对自身行为进行反省并表达悔过，但迟来的悔过仍未能平息大会的皮豆浪潮。

=== 退圈声明与意外收场 ===
最终，[[二向箔的投放者主任委员]]在大会上表示自己将退出协会并退出李文亚圈子。此时几位会员转而表示对其挽留。与此同时，大会上有代表提及河南高考，全体代表的注意力意外转向高考与教育议题，激烈讨论了各地升学形势，整场皮豆随之基本结束。会后，几位委员着手进行善后工作，包括主持评选新任主任委员、恢复协会会名牌匾、整理大会记录等。

== 影响 ==
# '''协会信任体系崩塌'''：[[二向箔的投放者主任委员]]苦心经营的虚假人设全面破产，协会内部人心浮动，多名会员开始重新审视协会既往决议的合法性。
# '''"+1事件"载入史册'''：主任委员在皮豆自己的刷屏中按下"+1"，成为李文亚宇宙组织史上的著名荒诞瞬间，被反复引用。
# '''与孙笑川团伙关系曝光'''：五项指控坐实了协会高层与[[孙笑川教授]]团伙勾结的传闻，使[[诺奖与民科研究交流协会]]的中立学术形象遭受重创。
# '''蜘蛛巢大学方面施压'''：[[蜘蛛巢大学]]因学生被女装诱骗一事对协会提出严正交涉，要求协会限期给出处理结果。
# '''委员积劳问题浮上水面'''：因危险鉴证内容招黑而被迫熬夜整肃会务的委员们集体发声，成为倒主任委员阵营的重要民意基础。
# '''权力交接启动'''：[[二向箔的投放者主任委员]]宣布退圈后，协会进入评选新任主任委员的程序，但其"宣布退出却未正式移交权限"的状态仍令善后工作存在隐忧。
# '''河南高考成为转折点'''：一场声势浩大的全体皮豆最终以高考与教育话题收场，被评论者称为"李文亚宇宙最具中国特色的冲突降温方式"。
# '''协会解散''': 2026年8月6日14时，[[诺奖与民科研究交流协会]]正式解散。
