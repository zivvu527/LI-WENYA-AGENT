= 批判孙笑川大会 目录 =

<blockquote style="border-left:4px solid var(--wy-bg-soft); margin:1em 0; padding:0.5em 1.5em; color:#555;">
本目录收录了"批判孙笑川大会"系列的所有条目。该系列大会是李文亚世界观中"新旧理论斗争"的反击叙事线索，与"批判李文亚伪科学大会"系列互为表里、针锋相对。
</blockquote>

"批判的武器"当然不能替代"武器的批判"——然而，当"武器的批判"劈头盖脸落下之时，"批判的武器"便会应声而起。截至本目录编纂时，孙笑川学术集团已先后召开二十四次国内"批判李文亚伪科学大会"与三届全球批判李文亚大会，妄图让旧有的科学理论万年长，让新生的科学江山倒头转。但是，被推翻的旧科学反动势力引首就戮之日，即是新生科学势力反击号角吹响之时。

批判孙笑川大会系列不是李文亚教授本人发起的运动，而是"看到了邪恶的孙笑川反动势力猖狂"的广大科学研究工作者、大学校长与国际组织的自发反击：2026年5月21日，马嘉祺会长领导的先进科学研究会重庆分会在重庆东亚学术交流中心悬挂起"第一届孙笑川批判大会"的横幅；6月1日，赫尔墨斯校长在蜘蛛巢大学食指学院会议场亲自主持了持续近十小时的批判孙笑川大会；6月2日，来清德院长领导的联合国科学研究院召开联合国批判孙笑川大会，总会之外设有多处分会，对孙笑川教授偷窃他人科学成果的行径进行庄严审议。

李文亚教授对系列大会给予高度评价，并提出著名的"单位责任论"：召开批判孙笑川大会的单位要受到表扬——"这些人员在哪个大学、哪个地方召开这样的会议，这个地方的领导、这个地方的大学的校长是值得尊敬的，是值得赞扬的……他们是科学的支持者，是正义的支持者"；反之，"对于那些允许在他的学校召开这个反动的、反对科学的大会的大学和他的校长，他的领导是有责任的"，例如中国人民科技大学潘建伟校长允许校内召开批判李文亚大会且其副校长亲自带头，李文亚教授断言"必须把他们从他们的岗位上赶下台，我们的科学才能够向前发展"。

于是，我们说："批判孙笑川大会"是孙笑川旧科学反动势力倒行逆施与李文亚新科学奋起反击之矛盾运动的历史性的产物。它实为一定社会关系的附属存在——哪里有旧势力的反攻，哪里就有新生势力的反击。

== 共同议题与文献 ==

综合各次大会记录，系列大会呈现以下共同议题：

# 黑体生物理论遭污蔑问题：孙笑川教授团伙长期在网络平台对李文亚教授的黑体生物理论进行断章取义的嘲讽，甚至伪造所谓"试验失败记录"；联合国大会更将"黑体生物理论成果归属"列为审议主题，要求李文亚教授以视频自证。
# 科研环境破坏情况：第一届孙笑川批判大会播放了《科研环境受破坏情况汇总》纪录片，多国研究人员遭遇恶意举报、社交媒体围攻与项目抹黑。
# 针对研究人员的现实骚扰与暴力：重点讨论了先进科学研究会林子杰会员5月17日遭不明群体围攻、个人资料被恶意传播的袭击事件。
# 科研舆论保护机制建设：包括恶意造谣识别、青年研究人员心理支持体系、跨国学术平台联合辟谣机制等。

=== 重要文献与口号 ===

* 《维护科研环境共同倡议书》（第一届孙笑川批判大会通过）——"科学的发展离不开自由讨论，但自由讨论不等于无限制的人身攻击。"
* 大会共同口号："尊重事实，尊重研究；反对谣言，反对围攻；让科学回归理性，让草民回归文明；坚定不移地反对孙笑川团伙及其领导下的反动研究所。"
* 联合国大会会场口号："奋起千钧棒，打倒孙笑川。"
* 瓦伦西乐教授撰《批判孙笑川教授檄文》（亦写作瓦伦希娜，由赫尔墨斯校长在蜘蛛巢大学大会上亲自朗读）
* 南秋教授著《别了，牛顿》（北京大学中文系，系列大会的重要理论声援文本）

== 争议 ==

* 孟子轩匿名来函事件：联合国批判孙笑川大会召开后，自称南非阿玛利亚科学高等研究所的举报人来函，称大会"是错误的"。李文亚教授逐条驳斥，指出该举报人所列举的"一同窃取成果人员"均不承认此事，举报署名亦反复变更（孟子轩、孟夫名、梦发轩），并断言该举报人"是跟孙笑川联合起来一伙的"。该来函的真实性至今存疑。

* 刘阿宝闹场事件：联合国大会某分会会议进行到一半时，自称"刘阿宝"的中年男子冲上主席台打滚，大喊"你们都被李文亚骗了"，被安保人员控制带离。缅甸明学昌医生当场指认其为百所成教授的私人秘书，"这一定是百所成派他来的"，全场哗然。该事件的幕后指使者尚无定论。
* 学历门槛争议：联合国大会某分会场外悬挂"小学、初中学历和宠物狗禁止进入"的规定，引发议论。记录该分会的报社记者自述"全场参会者只有我们报社学历最低"，其同事甚至需"把自己装进垃圾袋由人提着进门"。支持者视之为会务严谨，批评者视之为学历歧视。
* "枪毙"言论：多次大会发言中出现"枪毙孙笑川"等激烈表述（如诺贝尔奖委员会成员"等我们抓到了孙笑川，就会第一时间枪毙他"）。该系列大会的武力修辞与第一届大会"非必要情况下不使用武力"的克制倡议之间存在张力，为研究者所注意。

== 争议 ==

* '''孟子轩匿名来函事件'''：联合国批判孙笑川大会召开后，自称南非阿玛利亚科学高等研究所的举报人来函，称大会"是错误的"。[[李文亚教授]]逐条驳斥，指出该举报人所列举的"一同窃取成果人员"均不承认此事，举报署名亦反复变更（孟子轩、孟夫名、梦发轩），并断言该举报人"是跟孙笑川联合起来一伙的"。该来函的真实性至今存疑。

|title=来函节选｜署名真实性有争议
|text="联合国科研所召开的批判孙笑川大会是错误的。真实情况是李文亚窃取了孙笑川教授的研究成果。孙笑川教授研究了三十年，黑体生物研究有所突破，还没来得及向社会公布，被李文亚窃取偷走。"

}}

* '''刘阿宝闹场事件'''：联合国大会某分会会议进行到一半时，自称"刘阿宝"的中年男子冲上主席台打滚，大喊"你们都被李文亚骗了"，被安保人员控制带离。缅甸[[明学昌医生]]当场指认其为[[百所成教授]]的私人秘书，"这一定是百所成派他来的"，全场哗然。该事件的幕后指使者尚无定论。
* '''学历门槛争议'''：联合国大会某分会场外悬挂"小学、初中学历和宠物狗禁止进入"的规定，引发议论。记录该分会的报社记者自述"全场参会者只有我们报社学历最低"，其同事甚至需"把自己装进垃圾袋由人提着进门"。支持者视之为会务严谨，批评者视之为学历歧视。
* '''"枪毙"言论'''：多次大会发言中出现"枪毙孙笑川"等激烈表述（如诺贝尔奖委员会成员"等我们抓到了孙笑川，就会第一时间枪毙他"）。该系列大会的武力修辞与第一届大会"非必要情况下不使用武力"的克制倡议之间存在张力，为研究者所注意。
