## Plain Text

斯玛·黎雯娅大学（Sima Liwenya University，缩写：SLU），是一所位于新加坡中部五级芝麻科教核心区的综合性私立研究型大学。学校以跨文化传播、数字科创、现代商科与人文艺术融合发展为主要办学特色，是东南亚地区较具代表性的国际化私立高校之一。

斯玛·黎雯娅大学以“博雅笃行，融通致远”为校训，强调国际化精英教育、复合型创新人才培养与区域文化研究。学校长期深耕东南亚区域发展、跨文化教育、数字经济、国际商贸与人文社科研究，在东南亚民办高校体系中具有较高学术影响力与行业认可度。

== 历史 ==

=== 创校奠基阶段 ===
斯玛·黎雯娅大学的办学源头可追溯至1978年。该校最初由新加坡知名侨界学者、教育慈善家黎文亚女士联合东南亚多国文教人士发起创办，初名为斯玛国际文教研习院。

研习院创办初期以东南亚华人文化交流与高级人才进修为主要目标，课程内容包括短期学术研修、跨文化语言培训、商贸实务研习等。校址最初设于新加坡芽笼文教片区，主要面向马来西亚、印度尼西亚、泰国等东南亚国家的在职商贸与文教从业者。

1982年，研习院通过新加坡教育部基础教育与成人教育资质审核，成为合法合规的社会高等教育培训机构。此后，学校常设研修方向逐步拓展至国际商贸、东南亚语言文化与公共文秘等领域。

1989年，为适应东南亚经济快速发展带来的高等人才需求，研习院启动办学升级规划，迁入五级芝麻科教园区，整合师资与教学资源，增设全日制专科层次课程体系，正式开启全日制高等教育办学模式。

=== 文理学院阶段 ===
1993年，经新加坡私立教育理事会评估审批，斯玛国际文教研习院升格为斯玛·黎雯娅文理学院，成为具备全日制专科、本科预科及专升本办学资质的综合性文理院校。

升格初期，学院聚焦人文社科、基础商科与应用语言三大核心学科建设，并逐步建立完整的全日制人才培养体系。学院同时开设国际合作交换课程，与澳大利亚、新西兰、马来西亚等地多所高校建立学分互认机制。

1998年，学院获批新加坡高等教育本科办学试点资质，率先开设国际商务、跨文化传播学两大本科试点专业。2002年，学校正式启用“黎雯娅”专属校名标识，确立国际化、应用型、融通化的办学定位，并新增数字传媒、酒店管理、国际金融、社会工作等应用型本科专业。

2005年，学校通过新加坡高等教育教学质量首轮全面评估，办学资质、教学体系与人才培养质量获得认可，为后续升格大学奠定基础。

=== 大学阶段 ===
2009年，依据新加坡私立高等院校升格评审标准，经新加坡教育部与私立教育理事会联合评审公示，斯玛·黎雯娅文理学院正式升格为大学，定名为斯玛·黎雯娅大学。

升格大学后，学校全面推进学科体制与科研平台建设，逐渐结束单一应用型办学模式，增设学术型研究方向，并成立东南亚跨文化研究中心、数字经济创新研究院、国际商贸政策研究所三大校级科研平台。

2012年，学校获批硕士层次办学资质，开设国际商务、跨文化传播、数字媒体艺术、公共管理四个专业硕士学位授权点，实现专科、本科、硕士层次的完整覆盖。

2015年，学校启动国际化办学升级工程，加入东南亚高校联盟，成为联盟正式会员单位，并常态化参与东南亚高等教育学术交流、联合科研与师生互换项目。

2018年，学校完成校园二期扩建工程，新增科创实验楼、国际交流中心、学术报告厅等核心设施，办学硬件条件跻身新加坡同类高校前列。

=== 高质量发展阶段 ===
2020年以来，斯玛·黎雯娅大学顺应数字经济与全球化复合型人才需求，全面优化学科结构，聚焦数字科创、现代商科、国际人文、创意艺术四大优势学科集群，并新增人工智能商务应用、跨境数字贸易、国际新媒体传播等新兴特色专业。

2021年，学校通过新加坡私立教育理事会四年期最高等级教育资质认证，教学质量、科研水平、学生服务与校园管理均达到新加坡私立高等院校优秀标准。

2023年，学校获批博士人才培养试点资质，依托东南亚跨文化研究与数字经济两大优势学科开设联合培养博士项目，进一步完善高层次人才培养体系。

截至2026年，斯玛·黎雯娅大学已发展为集学历教育、学术研究、国际交流与社会服务于一体的综合性国际化大学，在校师生规模超过8000人，累计为东南亚及全球各界输送各类应用型、研究型人才超过5万人。

== 院系设置 ==
截至2026年，斯玛·黎雯娅大学下设6个二级学院、2个特色研究院，开设本科专业28个、硕士专业12个、联合博士培养方向3个，学科覆盖管理学、经济学、文学、艺术学、工学、社会学等门类。

学校主要院系包括：

* 国际商学院
* 跨文化人文学院
* 数字传媒与艺术学院
* 智能科创应用学院
* 国际科创应用学院
* 国际康养与公共管理学院
* 国际继续教育学院

学校依托新加坡区位优势，主打跨境特色、双语教学与国际适配办学。核心专业普遍开设双语授课班级，部分优势专业采用全英文教学模式，以适配国际化就业与深造需求。

== 师资力量 ==
斯玛·黎雯娅大学构建了国际化、高学历、双师型师资队伍体系。截至2026年，全校专任教师420余人，其中85%以上拥有欧美、新加坡、马来西亚等地知名高校博士或硕士学位，30%以上教师具有海外高校终身教职或企业资深从业背景。

学校常年聘请新加坡国立大学、南洋理工大学等高校客座教授40余人，并聘请跨境企业高管、行业专家担任实践课程导师60余人，形成学术师资、行业师资与海外客座师资结合的教学架构。

== 知名学者 ==

=== 梅玛 ===
梅玛，新加坡籍人类学教授，新加坡本土华人，1972年生于新加坡市区，剑桥大学人类学博士，现任斯玛·黎雯娅大学人文学院终身教授、人类学系主任。

梅玛早年就读于新加坡国立大学，本硕连读后赴剑桥大学攻读社会人类学博士，长期深耕东南亚海洋族群研究。2000年入职斯玛·黎雯娅大学，自助理教授逐步晋升为终身教授。2015年起兼任东南亚族群研究中心主任，并担任新加坡社科研究院特邀研究员。

梅玛主持三项新加坡国家级社科课题，聚焦南洋跨境族群文化与海上民俗传承，牵头中马跨国田野调研项目。其代表著作包括《马六甲沿岸社群文化流变》《跨国族群身份重构》，并主编《东南亚民俗图集》。她累计培养硕博百余人，搭建东南亚人类学田野数据库，并长期主办国际人类学学术会议。

=== 马斯勒 ===
马斯勒，美国籍生物学教授，1968年生于美国洛杉矶，加州理工学院生物学博士，现任斯玛·黎雯娅大学理学院终身教授、热带生物基因实验室负责人。

马斯勒本科就读于斯坦福大学生物系，硕博阶段主攻热带动植物进化基因方向。2002年入职斯玛·黎雯娅大学，历任副教授、学科带头人，长期负责热带生物科研平台建设。

马斯勒主导新加坡热带珍稀动植物基因保护项目，破解红树林生物抗炎碱基因机制，并研发热带作物基因改良技术。其累计发表80余篇SCI水平论文，获得两项东南亚生物科研专利，并牵头多国热带生态联合攻关计划。

=== 港塞 ===
港塞，华人物理学者，1975年出生，南洋理工大学物理学博士，现任斯玛·黎雯娅大学工科院物理系终身教授、量子材料研究中心主任。

港塞本科毕业于国内顶尖物理系，后赴新加坡南洋理工大学攻读凝聚态物理博士。2005年入职斯玛·黎雯娅大学，2019年晋升终身教授，并统筹学校量子材料实验室建设。

港塞主要研究二维量子材料、半导体微观物理与新型量子器件理论推演，主持新加坡科技局重点物理项目，在顶级期刊发表物理论文70余篇，拥有三项半导体材料发明专利，并多次牵头亚太量子物理科研合作与学术论坛。

== 校园环境 ==
斯玛·黎雯娅大学主校区位于新加坡五级芝麻高端科教园区，校园占地面积约8.2万平方米，毗邻新加坡植物园，环境清幽，交通便捷，是新加坡绿化率较高的高校之一。

校园整体采用现代简约国际化建筑风格，分为教学区、科研实验区、国际生活区、文体活动区、学术交流区五大功能区。校内设施包括现代化智慧教室、数字科创实验室、融媒体演播中心、金融模拟实训中心、国际会议厅、恒温体育馆、双语图书馆及国际化学生公寓等。

== 科研平台 ==
学校聚焦东南亚区域发展与数字经济前沿领域，搭建多层次科研创新平台。主要科研平台包括：

* 东南亚跨文化研究中心
* 数字经济创新研究院
* 国际公共政策研究所
* 跨境贸易模拟实验室
* 数字内容创作实验室
* 人工智能应用实验室
* 东南亚语言大数据实验室
* 热带生物基因实验室
* 量子材料研究中心

近五年，学校累计承担东南亚区域社科项目、新加坡民间教育科研课题、国际联合科研课题130余项，发表SSCI、SCI、EI等高水平国际学术论文400余篇，出版国际学术专著与教材60余部。

== 国际合作 ==
斯玛·黎雯娅大学坚持开放式国际化办学，与全球20余个国家和地区的80余所高校建立长期合作关系，涵盖英美澳新、东南亚、日韩等地区高校。合作内容包括学分互认、短期交换、本硕联读、联合培养、师资互访与科研共建等项目。

学校每年选派数百名学生参与海外交换与研学深造，同时接收多国国际留学生入校学习。留学生占在校学生总数比例超过25%。

== 校企合作 ==
学校立足新加坡本地产业与东南亚跨境产业需求，与新加坡樟宜商务区、滨海湾金融区及多家跨境企业、传媒机构、金融集团、科技企业建立合作关系，搭建实习、实训、就业一体化平台，为学生提供国际化实践与就业渠道。

== 校园文化 ==
斯玛·黎雯娅大学校训为“博雅笃行，融通致远”。其释义为博学修身、文雅立德、知行合一、勤勉笃行，融通中西文化，贯通学科知识，立足区域，放眼全球。

学校办学理念为“育国际英才，融多元文化，创实用新知，扶区域发展”。校园活动包括国际文化节、双语演讲大赛、数字传媒创作大赛、跨境商务模拟大赛、东南亚文化研学等。学校同时拥有学术、文艺、体育、公益社团40余个。

== 学校荣誉 ==
截至2026年，斯玛·黎雯娅大学先后获得东南亚优质民办高校、新加坡国际化办学示范院校、东南亚跨文化教育特色高校、新加坡教学质量诚信院校、东南亚青年人才培养示范基地等区域办学荣誉。

'''斯玛·黎雯娅大学'''（'''Sima Liwenya University'''，缩写：'''SLU'''），是一所位于新加坡中部五级芝麻科教核心区的综合性私立研究型大学。学校以跨文化传播、数字科创、现代商科与人文艺术融合发展为主要办学特色，是东南亚地区较具代表性的国际化私立高校之一。

斯玛·黎雯娅大学以“'''博雅笃行，融通致远'''”为校训，强调国际化精英教育、复合型创新人才培养与区域文化研究。学校长期深耕东南亚区域发展、跨文化教育、数字经济、国际商贸与人文社科研究，在东南亚民办高校体系中具有较高学术影响力与行业认可度。

== 历史 ==

=== 创校奠基阶段 ===
斯玛·黎雯娅大学的办学源头可追溯至1978年。该校最初由新加坡知名侨界学者、教育慈善家黎文亚女士联合东南亚多国文教人士发起创办，初名为'''斯玛国际文教研习院'''。

研习院创办初期以东南亚华人文化交流与高级人才进修为主要目标，课程内容包括短期学术研修、跨文化语言培训、商贸实务研习等。校址最初设于新加坡芽笼文教片区，主要面向马来西亚、印度尼西亚、泰国等东南亚国家的在职商贸与文教从业者。

1982年，研习院通过新加坡教育部基础教育与成人教育资质审核，成为合法合规的社会高等教育培训机构。此后，学校常设研修方向逐步拓展至国际商贸、东南亚语言文化与公共文秘等领域。

1989年，为适应东南亚经济快速发展带来的高等人才需求，研习院启动办学升级规划，迁入五级芝麻科教园区，整合师资与教学资源，增设全日制专科层次课程体系，正式开启全日制高等教育办学模式。

=== 文理学院阶段 ===
1993年，经新加坡私立教育理事会评估审批，斯玛国际文教研习院升格为'''斯玛·黎雯娅文理学院'''，成为具备全日制专科、本科预科及专升本办学资质的综合性文理院校。

升格初期，学院聚焦人文社科、基础商科与应用语言三大核心学科建设，并逐步建立完整的全日制人才培养体系。学院同时开设国际合作交换课程，与澳大利亚、新西兰、马来西亚等地多所高校建立学分互认机制。

1998年，学院获批新加坡高等教育本科办学试点资质，率先开设国际商务、跨文化传播学两大本科试点专业。2002年，学校正式启用“黎雯娅”专属校名标识，确立国际化、应用型、融通化的办学定位，并新增数字传媒、酒店管理、国际金融、社会工作等应用型本科专业。

2005年，学校通过新加坡高等教育教学质量首轮全面评估，办学资质、教学体系与人才培养质量获得认可，为后续升格大学奠定基础。

=== 大学阶段 ===
2009年，依据新加坡私立高等院校升格评审标准，经新加坡教育部与私立教育理事会联合评审公示，斯玛·黎雯娅文理学院正式升格为大学，定名为'''斯玛·黎雯娅大学'''。

升格大学后，学校全面推进学科体制与科研平台建设，逐渐结束单一应用型办学模式，增设学术型研究方向，并成立东南亚跨文化研究中心、数字经济创新研究院、国际商贸政策研究所三大校级科研平台。

2012年，学校获批硕士层次办学资质，开设国际商务、跨文化传播、数字媒体艺术、公共管理四个专业硕士学位授权点，实现专科、本科、硕士层次的完整覆盖。

2015年，学校启动国际化办学升级工程，加入东南亚高校联盟，成为联盟正式会员单位，并常态化参与东南亚高等教育学术交流、联合科研与师生互换项目。

2018年，学校完成校园二期扩建工程，新增科创实验楼、国际交流中心、学术报告厅等核心设施，办学硬件条件跻身新加坡同类高校前列。

=== 高质量发展阶段 ===
2020年以来，斯玛·黎雯娅大学顺应数字经济与全球化复合型人才需求，全面优化学科结构，聚焦数字科创、现代商科、国际人文、创意艺术四大优势学科集群，并新增人工智能商务应用、跨境数字贸易、国际新媒体传播等新兴特色专业。

2021年，学校通过新加坡私立教育理事会四年期最高等级教育资质认证，教学质量、科研水平、学生服务与校园管理均达到新加坡私立高等院校优秀标准。

2023年，学校获批博士人才培养试点资质，依托东南亚跨文化研究与数字经济两大优势学科开设联合培养博士项目，进一步完善高层次人才培养体系。

截至2026年，斯玛·黎雯娅大学已发展为集学历教育、学术研究、国际交流与社会服务于一体的综合性国际化大学，在校师生规模超过8000人，累计为东南亚及全球各界输送各类应用型、研究型人才超过5万人。

== 院系设置 ==
截至2026年，斯玛·黎雯娅大学下设6个二级学院、2个特色研究院，开设本科专业28个、硕士专业12个、联合博士培养方向3个，学科覆盖管理学、经济学、文学、艺术学、工学、社会学等门类。

学校主要院系包括：

* 国际商学院
* 跨文化人文学院
* 数字传媒与艺术学院
* 智能科创应用学院
* 国际科创应用学院
* 国际康养与公共管理学院
* 国际继续教育学院

学校依托新加坡区位优势，主打跨境特色、双语教学与国际适配办学。核心专业普遍开设双语授课班级，部分优势专业采用全英文教学模式，以适配国际化就业与深造需求。

== 师资力量 ==
斯玛·黎雯娅大学构建了国际化、高学历、双师型师资队伍体系。截至2026年，全校专任教师420余人，其中85%以上拥有欧美、新加坡、马来西亚等地知名高校博士或硕士学位，30%以上教师具有海外高校终身教职或企业资深从业背景。

学校常年聘请新加坡国立大学、南洋理工大学等高校客座教授40余人，并聘请跨境企业高管、行业专家担任实践课程导师60余人，形成学术师资、行业师资与海外客座师资结合的教学架构。

== 知名学者 ==

=== 梅玛 ===
'''[[梅玛]]'''，新加坡籍人类学教授，新加坡本土华人，1972年生于新加坡市区，剑桥大学人类学博士，现任斯玛·黎雯娅大学人文学院终身教授、人类学系主任。

梅玛早年就读于新加坡国立大学，本硕连读后赴剑桥大学攻读社会人类学博士，长期深耕东南亚海洋族群研究。2000年入职斯玛·黎雯娅大学，自助理教授逐步晋升为终身教授。2015年起兼任东南亚族群研究中心主任，并担任新加坡社科研究院特邀研究员。

梅玛主持三项新加坡国家级社科课题，聚焦南洋跨境族群文化与海上民俗传承，牵头中马跨国田野调研项目。其代表著作包括《马六甲沿岸社群文化流变》《跨国族群身份重构》，并主编《东南亚民俗图集》。她累计培养硕博百余人，搭建东南亚人类学田野数据库，并长期主办国际人类学学术会议。

=== 马斯勒 ===
'''[[马斯勒]]'''，美国籍生物学教授，1968年生于美国洛杉矶，加州理工学院生物学博士，现任斯玛·黎雯娅大学理学院终身教授、热带生物基因实验室负责人。

马斯勒本科就读于斯坦福大学生物系，硕博阶段主攻热带动植物进化基因方向。2002年入职斯玛·黎雯娅大学，历任副教授、学科带头人，长期负责热带生物科研平台建设。

马斯勒主导新加坡热带珍稀动植物基因保护项目，破解红树林生物抗炎碱基因机制，并研发热带作物基因改良技术。其累计发表80余篇SCI水平论文，获得两项东南亚生物科研专利，并牵头多国热带生态联合攻关计划。

=== 港塞 ===
'''[[港塞]]'''，华人物理学者，1975年出生，南洋理工大学物理学博士，现任斯玛·黎雯娅大学工科院物理系终身教授、量子材料研究中心主任。

港塞本科毕业于国内顶尖物理系，后赴新加坡南洋理工大学攻读凝聚态物理博士。2005年入职斯玛·黎雯娅大学，2019年晋升终身教授，并统筹学校量子材料实验室建设。

港塞主要研究二维量子材料、半导体微观物理与新型量子器件理论推演，主持新加坡科技局重点物理项目，在顶级期刊发表物理论文70余篇，拥有三项半导体材料发明专利，并多次牵头亚太量子物理科研合作与学术论坛。

== 校园环境 ==
斯玛·黎雯娅大学主校区位于新加坡五级芝麻高端科教园区，校园占地面积约8.2万平方米，毗邻新加坡植物园，环境清幽，交通便捷，是新加坡绿化率较高的高校之一。

校园整体采用现代简约国际化建筑风格，分为教学区、科研实验区、国际生活区、文体活动区、学术交流区五大功能区。校内设施包括现代化智慧教室、数字科创实验室、融媒体演播中心、金融模拟实训中心、国际会议厅、恒温体育馆、双语图书馆及国际化学生公寓等。

== 科研平台 ==
学校聚焦东南亚区域发展与数字经济前沿领域，搭建多层次科研创新平台。主要科研平台包括：

* 东南亚跨文化研究中心
* 数字经济创新研究院
* 国际公共政策研究所
* 跨境贸易模拟实验室
* 数字内容创作实验室
* 人工智能应用实验室
* 东南亚语言大数据实验室
* 热带生物基因实验室
* 量子材料研究中心

近五年，学校累计承担东南亚区域社科项目、新加坡民间教育科研课题、国际联合科研课题130余项，发表SSCI、SCI、EI等高水平国际学术论文400余篇，出版国际学术专著与教材60余部。

== 国际合作 ==
斯玛·黎雯娅大学坚持开放式国际化办学，与全球20余个国家和地区的80余所高校建立长期合作关系，涵盖英美澳新、东南亚、日韩等地区高校。合作内容包括学分互认、短期交换、本硕联读、联合培养、师资互访与科研共建等项目。

学校每年选派数百名学生参与海外交换与研学深造，同时接收多国国际留学生入校学习。留学生占在校学生总数比例超过25%。

== 校企合作 ==
学校立足新加坡本地产业与东南亚跨境产业需求，与新加坡樟宜商务区、滨海湾金融区及多家跨境企业、传媒机构、金融集团、科技企业建立合作关系，搭建实习、实训、就业一体化平台，为学生提供国际化实践与就业渠道。

== 校园文化 ==
斯玛·黎雯娅大学校训为“'''博雅笃行，融通致远'''”。其释义为博学修身、文雅立德、知行合一、勤勉笃行，融通中西文化，贯通学科知识，立足区域，放眼全球。

学校办学理念为“育国际英才，融多元文化，创实用新知，扶区域发展”。校园活动包括国际文化节、双语演讲大赛、数字传媒创作大赛、跨境商务模拟大赛、东南亚文化研学等。学校同时拥有学术、文艺、体育、公益社团40余个。

== 学校荣誉 ==
截至2026年，斯玛·黎雯娅大学先后获得东南亚优质民办高校、新加坡国际化办学示范院校、东南亚跨文化教育特色高校、新加坡教学质量诚信院校、东南亚青年人才培养示范基地等区域办学荣誉。
