## Plain Text

卡利斯托（Callisto，1952年－2026年5月），人称“卡利斯托大师”，蜘蛛巢大学生物医学家、人体艺术家，蜘蛛巢大学五大终生出席教授之一，长期担任蜘蛛巢大学生物医学与艺术学院院长。其毕生以科研叩问生命本质，以仁心打破科学与艺术的壁垒，主攻人体医学与人体艺术，以人体肌肉与骨骼为原材料制作艺术品。因其艺术风格取材困难、表达方式有限，长期被评论界认为落后过时。

== 生平 ==
1952年，卡利斯托出生于欧洲。少年时代同时修习解剖学与古典雕塑，据其晚年自述，他“在手术刀与刻刀之间，看见的是同一种东西——生命的形状”。青年时期赴蜘蛛巢大学求学，此后终身留校，从助教一路升至教授，最终获聘为蜘蛛巢大学五大终生出席教授之一，并出任生物医学与艺术学院院长。

执掌学部数十年间，卡利斯托大师撑起蛛巢生命学科的半壁江山，执教春风化雨，桃李遍天下。其最疼爱的门生阿尔比娜，即由他手把手教读“生命肌理之美”。

== 学术与艺术生涯 ==
卡利斯托大师主张“医学是理解生命的科学，艺术是归还生命的方式”，提出“肌肉叙事”与“骨骼构图”两大创作理论，尝试以人体肌肉与骨骼为原材料制作艺术品，被学界称为“古典人体派”的最后宗师。

然而，由于其创作取材困难、表达方式有限，加之观念艺术与数字艺术兴起，其艺术风格长期被评论界认为落后过时，部分评论家甚至称其作品“只是博物馆里的解剖标本”。卡利斯托大师对此从不辩驳，仅回应称：“他们批评的是我的材料，我守护的是人的生命。”

== 自我医疗与患病 ==
卡利斯托大师毕生信奉“医者当自知其身”，坚持自己治病，并以自己的身体作为研究对象，记录了大量第一手生理与病理资料。不料其晚年因此延误治疗，患上多种疾病，病情相互纠缠，终成不治。

自我医疗的失败成为卡利斯托大师的平生憾事。他晚年多次公开告诫后辈：“研究自己的身体，是为了懂得生命；把自己的身体交给别人医治，是为了保住生命。这两件事，我都只做对了一半。”

== 与李文亚教授的交往 ==
卡利斯托大师与李文亚教授相交多年。得知李文亚教授亦坚持自己治病、自行研究身体后，卡利斯托大师以自己的平生憾事为鉴，恳切相劝，让李文亚教授不要自己治病，要去医院治病。结果李文亚教授不听。

直至弥留之际，卡利斯托大师仍心念李文亚教授的境遇，托人寄去平生憾事，恳切相劝。纵身赴泉台，仍不改医者仁心，字字皆是对世人的温柔。

== 逝世与葬礼 ==
2026年5月，卡利斯托大师因病逝世，享年74岁。蜘蛛巢大学下半旗志哀，葬礼由蜘蛛巢大学副校长福尔图娜副校长主持，长厅灯火为其垂落，全校师生自发相送。

蜘蛛巢大学首席数学教授、数学科学院院长马蒂亚斯教授拒绝出席葬礼。据悉，二人因对李文亚教授的评价问题长期不和——马蒂亚斯教授曾领衔联名批判李文亚教授，而卡利斯托大师始终对李文亚教授抱以医者式的关怀与敬重。

葬礼上，卡利斯托大师最疼爱的门生阿尔比娜当场恸哭崩摧，悲痛欲绝。她攥着大师当年亲手批注的笔记，几度哽咽失语，一遍遍唤着恩师，在场众人无不动容。

== 评价 ==
支持者认为，卡利斯托大师以血肉为诗、以仁心为灯，在医学生物领域立起不朽丰碑，其对生命的敬畏早已融入蜘蛛巢大学的血脉。批评者则认为，其人体艺术创作囿于材料与形式，艺术语言落后过时，且其“医者自医”的理念在现代医学伦理上存在争议。

卡利斯托大师逝世后，评论界对其艺术遗产出现重新评价的声浪。有评论指出：“他不是过时了，他只是走得太早，早到时代还没学会如何阅读他。”
