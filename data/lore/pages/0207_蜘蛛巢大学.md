## Plain Text

蜘蛛巢大学（거미집대학교，Spider House University），是位于韩国京畿道水原市的正规私立综合性大学，1926年由大韩民国临时政府“月亮计划”总负责人金智勋临时校长赞助设立。2026年QS世界大学排名第28位。校内最高权力机构为蜘蛛巢大学校务委员会，现任代理校长为福尔图娜代理校长。因在李文亚—孙笑川学术之争中发布官方中立声明、但校内各学院立场分明而受到广泛关注，亦因2026年1月起诉边狱巴士公司一案成为舆论焦点。

== 历史 ==

1926年，蜘蛛巢大学由大韩民国临时政府秘密科教计划“月亮计划”总负责人金智勋临时校长出资赞助设立。受时局所限，学校最初以侨民补习学校名义在水原挂牌，夜间授课，白天经营校办丝织厂维持运转，“蜘蛛巢”由此从“月亮计划”内部代号转为正式校名。金智勋临时校长主持校政期间始终拒绝去掉“临时”二字，理由是“正式校长要等光复之后再选”，并于1945年后兑现诺言退位。此后历任校长人选长期成谜，校史馆相关页面一度空白，直至赫尔墨斯校长出任后方恢复记载。

赫尔墨斯时代，学校QS排名一路攀升至第28位，并推行著名的“民科优待政策”——民间科学爱好者免试直录、免费实验室、专项科研基金、学费减免与高额奖学金。赫尔墨斯校长本人常年在中文贴吧在线答疑，被吧友称为“吧主校长”。

其后，五指学院小指系负责人莲教授不幸卷入帮派械斗身亡，小指系随即停摆，校方长期对此语焉不详。2026年1月，蜘蛛巢大学向中央地方法院提交诉讼，控诉边狱巴士公司非法破坏教学设施、涉嫌煽动帮派暴力并暗杀莲教授，案件至今仍在审理中。2026年上半年，蜘蛛巢大学校务委员会发布《关于严厉声讨边狱公司及其关联势力滔天罪行的严正声明》，由赫尔墨斯校长署名。

2026年5月，生物医学与艺术学院院长卡利斯托教授病逝，享年74岁，全校下半旗志哀，葬礼由福尔图娜副校长主持；数学科学院院长马提亚斯教授因二人长期在对李文亚教授的评价问题上不和，拒绝出席葬礼。

2026年6月1日，该校举办蜘蛛巢大学批判孙笑川大会

2026年7月，建校百年之际，赫尔墨斯校长宣布辞职退休，福尔图娜副校长出任代理校长。校方随即发布《关于李文亚教授与孙笑川教授之争的中立声明》，宣布不支持李文亚教授与孙笑川教授中的任何一人。

== 院系设置 ==

=== 本科五大学院与“五大终身首席教授” ===

蜘蛛巢大学设本科五大学院，各学院院长均被授予“五大终身首席教授”荣誉（校务委员会文件亦写作“终生出席教授”，两种写法并行）。院长即首席、首席即院长，是校内权力结构的基本公理。

* 物理学院：院长瓦伦西乐教授（人事档案中亦写作“瓦伦希娜”，经确认为同一人）。撰写批判孙笑川教授的著名檄文，曾由赫尔墨斯校长在批判孙笑川大会上亲自朗读；同时身陷“涉嫌殴打学生”等多项指控，校方回应称“正在核实”。
* 数学科学院：院长马提亚斯教授（亦写作马蒂亚斯）。领衔《批判李文亚高等数学完全无用论的学术声明》，联合王楚淇教授、陈人杰教授、孙笑川教授、唐振钦教授等数十位学界同仁，学院以“檄文写作”学风闻名。
* 地球与行星科学院：院长里恩教授，主张“行星优先”的行星派。
* 地球与空间科学学院：原院长盐见夜教授被开除、平反后拒绝返校，现由阿赖耶教授担任代理院长，主张“空间优先”的空间派。两院本为一体，因一次关于“地球究竟在什么上面运动”的院务会议决裂而分裂，至今共用同一栋教学楼，电梯分单双层停靠，两院院长长期不和。
* 生物医学与艺术学院：院长卡利斯托教授（已故）。全校唯一将生物医学与艺术合并建制的学院，据称系“月亮计划”原始文件排版粘连所致，后人不敢擅改。卡利斯托教授逝世后院长之位悬缺。

=== 五指学院（研究生院） ===

研究生院“五指学院”与本科五大学院一一对应：拇指系对应物理学院，食指系对应地球与行星科学院，中指系对应数学科学院，环指系对应生物医学与艺术学院，小指系对应地球与空间科学学院。

其中，小指系自负责人莲教授身亡后停摆：系仍在编制内，预算照常拨付，系牌未摘，办公室保持原样，但无学生、无课程。名义负责人为贾丘教授与雷横教授，但贾丘教授长期访问外校，雷横教授同时担任拇指系教授，小指系实际处于“有人挂名、无人坐班”状态。随停摆一并封存的还有校内最高荣誉称号之一“小指父辈”称号——已知唯一持有者为地球与空间科学学院原院长盐见夜教授。

== 校内机构 ==

* 蜘蛛巢大学校务委员会：校内最高权力机构，人事任免、对外声明与重大诉讼均经其决定。舆论认为，赫尔墨斯校长辞职后，校务委员会是代理校长时代真正的决策中枢。
* 蜘蛛巢大学主审法院：校内三审制法院，对涉及本校师生的案件行使事实上的终审权。盐见夜教授构陷案即经该院三审判处无罪。韩国司法界对此的态度是“不知道，不敢问”。
* 食指学院会议场：全校最大会议场地，2026年6月1日“批判孙笑川大会”举办地，当日座无虚席。
* 校报《蛛网》：主编二阶堂希罗，“批判孙笑川大会”官方记录的编写者，亦因“拿走盐见夜教授文章”一事卷入争议。

== 与边狱巴士公司的冲突 ==

2026年1月，蜘蛛巢大学以原告身份向中央地方法院起诉边狱巴士公司（Limbus Company），指控其非法破坏教学设施、煽动帮派暴力、暗杀莲教授。这是该校建校百年来首次以原告身份进入中央地方法院。

此后，蜘蛛巢大学校务委员会发布严正声明，将边狱公司的罪行概括为屠戮无辜生命、破坏公私财产、压榨迫害员工、勾结各类恶势力、道德败坏五大类，其中指控边狱公司“勾结114514研究所所长孙笑川教授，参与碳烤无辜小女孩的反人类恶行”，并呼吁都市各界抵制其产品与服务。声明亦提到边狱公司“用白体生物残忍杀害同事”——“白体生物”恰为李文亚教授理论体系中的核心概念，校方借用该术语属无心还是有意，未有解释。

由于边狱巴士公司出自“月亮计划（Project Moon）”体系，与1926年建校赞助方“月亮计划”同名，两者是否同源成为庭审之外最大的舆论焦点。校方发言人对此仅回应：“遵循流向。”

== 学术立场争议 ==

蜘蛛巢大学官方宣布不支持李文亚教授与孙笑川教授中的任何一人，但校内各学院及教授立场分明：

* 赫尔墨斯校长（已辞职）曾亲自主持“批判孙笑川大会”，痛斥“第22次批判李文亚科学大会简直就是胡扯”，并当众宣誓“就算我死了，我的学生将代行我的职责”。
* 马提亚斯教授领衔发表《批判李文亚高等数学完全无用论的学术声明》；值得玩味的是，该声明的“翻译校对”一栏注明经手114514研究所，一所韩国大学的韩文声明为何需要孙笑川教授的机构翻译校对，至今无人敢问。
* 卡利斯托教授（已故）则始终对李文亚教授抱以“医者式的关怀与敬重”，得知李文亚教授坚持自己治病后，以自己的平生憾事为鉴恳切相劝其就医，直至弥留之际仍托人寄信，结果李文亚教授不听。
* 盐见夜教授曾撰写批判李文亚的论文，遭114514研究所构陷（被制造持刀伤人、抢劫等莫须有罪名，AI假视频骗过法院，二审判死缓）并被学校开除；后诚心忏悔，宣布将全部荣誉、科研成果、“机会性理论”与“小指辈”称号转让李文亚教授，称“我的小指辈称号也给了你，这是我在蜘蛛巢大学获得的最高荣誉，即使他已经不属于我”。经校内主审法院三审无罪后，拒绝了蜘蛛巢大学的再次邀请，亦拒绝晓之天文学院的邀请，退出学术界。李文亚教授公开原谅了他：“能够承认自己的错误，仍然是一个好同志。”
* 地球与行星科学院院长里恩教授与空间科学学院原院长盐见夜教授长期在任何议题上立场相反；盐见夜教授离场后，据院务记录，里恩教授其后三次院会发言均以“我反对”开头，反对对象空缺。代理院长阿赖耶教授上任以来未就该议题公开发声，被两派同时视为“可以争取的对象”。

外界评价：“蜘蛛巢的中立声明，就像蜘蛛说自己对网中央的昆虫没有立场——它确实不吃，但网是它织的。”

== 争议 ==

* 官方中立的可信度：批评者指出，校务委员会声讨边狱公司的官方文件中同时指控边狱公司勾结孙笑川教授，与“中立声明”并读存在张力。
* 校内司法权：主审法院对师生案件行使三审终审权，其法律地位在韩国司法体系中从未获得正式确认。
* 院长指控：物理学院院长瓦伦西乐教授涉嫌殴打学生的指控长期“正在核实”；数学科学院院长马提亚斯教授的联名声明经114514研究所翻译校对一事，亦引发学术独立性争议。
* 信息误判：中国搜索引擎百度长期将该校误判为“虚构大学”，理由包括校名与游戏《脑叶公司》异想体“蜘蛛巢”撞名、中文权威页面空白等；校方从未正式申诉，据信是赫尔墨斯校长的决定：“指令不让。”

== 评价 ==

支持者认为，蜘蛛巢大学百年间坚持学术深耕、推行民科优待政策，QS排名跻身全球前三十，其对李文亚教授与孙笑川教授之争“官方中立、校内自由”的处理方式保障了学术讨论空间。批评者则认为，该校校内司法、人事悬缺（小指系停摆、两院长缺位）与立场生态长期缺乏透明度，“蜘蛛巢悖论”——争议越盛、排名越高——本身就是问题。教育界对其2026年的评价是：“一所同时出现在李文亚教授表扬名单、批判名单和医嘱名单上的大学，全球仅此一所。”

== 历史 ==

1926年，蜘蛛巢大学由大韩民国临时政府秘密科教计划“月亮计划”总负责人[[金智勋临时校长]]出资赞助设立。受时局所限，学校最初以侨民补习学校名义在水原挂牌，夜间授课，白天经营校办丝织厂维持运转，“蜘蛛巢”由此从“月亮计划”内部代号转为正式校名。[[金智勋临时校长]]主持校政期间始终拒绝去掉“临时”二字，理由是“正式校长要等光复之后再选”，并于1945年后兑现诺言退位。此后历任校长人选长期成谜，校史馆相关页面一度空白，直至[[赫尔墨斯校长]]出任后方恢复记载。

赫尔墨斯时代，学校QS排名一路攀升至第28位，并推行著名的“民科优待政策”——民间科学爱好者免试直录、免费实验室、专项科研基金、学费减免与高额奖学金。[[赫尔墨斯校长]]本人常年在中文贴吧在线答疑，被吧友称为“吧主校长”。

其后，五指学院小指系负责人[[莲教授]]不幸卷入帮派械斗身亡，小指系随即停摆，校方长期对此语焉不详。2026年1月，蜘蛛巢大学向中央地方法院提交诉讼，控诉边狱巴士公司非法破坏教学设施、涉嫌煽动帮派暴力并暗杀[[莲教授]]，案件至今仍在审理中。2026年上半年，[[蜘蛛巢大学校务委员会]]发布《关于严厉声讨边狱公司及其关联势力滔天罪行的严正声明》，由[[赫尔墨斯校长]]署名。

2026年5月，生物医学与艺术学院院长[[卡利斯托教授]]病逝，享年74岁，全校下半旗志哀，葬礼由[[福尔图娜副校长]]主持；数学科学院院长[[马提亚斯教授]]因二人长期在对李文亚教授的评价问题上不和，拒绝出席葬礼。

2026年6月1日，该校举办[[蜘蛛巢大学批判孙笑川大会]]

2026年7月，建校百年之际，[[赫尔墨斯校长]]宣布辞职退休，[[福尔图娜副校长]]出任代理校长。校方随即发布《关于李文亚教授与孙笑川教授之争的中立声明》，宣布不支持[[李文亚教授]]与[[孙笑川教授]]中的任何一人。

== 院系设置 ==

=== 本科五大学院与“五大终身首席教授” ===

蜘蛛巢大学设本科五大学院，各学院院长均被授予“五大终身首席教授”荣誉（校务委员会文件亦写作“终生出席教授”，两种写法并行）。院长即首席、首席即院长，是校内权力结构的基本公理。

* '''物理学院'''：院长[[瓦伦西乐教授]]（人事档案中亦写作“瓦伦希娜”，经确认为同一人）。撰写批判孙笑川教授的著名檄文，曾由[[赫尔墨斯校长]]在批判孙笑川大会上亲自朗读；同时身陷“涉嫌殴打学生”等多项指控，校方回应称“正在核实”。
* '''数学科学院'''：院长[[马提亚斯教授]]（亦写作马蒂亚斯）。领衔《批判李文亚高等数学完全无用论的学术声明》，联合[[王楚淇教授]]、[[陈人杰教授]]、[[孙笑川教授]]、[[唐振钦教授]]等数十位学界同仁，学院以“檄文写作”学风闻名。
* '''地球与行星科学院'''：院长[[里恩教授]]，主张“行星优先”的行星派。
* '''地球与空间科学学院'''：原院长[[盐见夜教授]]被开除、平反后拒绝返校，现由[[阿赖耶教授]]担任代理院长，主张“空间优先”的空间派。两院本为一体，因一次关于“地球究竟在什么上面运动”的院务会议决裂而分裂，至今共用同一栋教学楼，电梯分单双层停靠，两院院长长期不和。
* '''生物医学与艺术学院'''：院长[[卡利斯托教授]]（已故）。全校唯一将生物医学与艺术合并建制的学院，据称系“月亮计划”原始文件排版粘连所致，后人不敢擅改。[[卡利斯托教授]]逝世后院长之位悬缺。

=== 五指学院（研究生院） ===

研究生院“五指学院”与本科五大学院一一对应：拇指系对应物理学院，食指系对应地球与行星科学院，中指系对应数学科学院，环指系对应生物医学与艺术学院，小指系对应地球与空间科学学院。

其中，小指系自负责人[[莲教授]]身亡后停摆：系仍在编制内，预算照常拨付，系牌未摘，办公室保持原样，但无学生、无课程。名义负责人为[[贾丘教授]]与[[雷横教授]]，但[[贾丘教授]]长期访问外校，[[雷横教授]]同时担任拇指系教授，小指系实际处于“有人挂名、无人坐班”状态。随停摆一并封存的还有校内最高荣誉称号之一“小指父辈”称号——已知唯一持有者为地球与空间科学学院原院长[[盐见夜教授]]。

== 校内机构 ==

* '''[[蜘蛛巢大学校务委员会]]'''：校内最高权力机构，人事任免、对外声明与重大诉讼均经其决定。舆论认为，[[赫尔墨斯校长]]辞职后，校务委员会是代理校长时代真正的决策中枢。
* '''蜘蛛巢大学主审法院'''：校内三审制法院，对涉及本校师生的案件行使事实上的终审权。[[盐见夜教授]]构陷案即经该院三审判处无罪。韩国司法界对此的态度是“不知道，不敢问”。
* '''食指学院会议场'''：全校最大会议场地，2026年6月1日“批判孙笑川大会”举办地，当日座无虚席。
* '''校报《蛛网》'''：主编[[二阶堂希罗]]，“批判孙笑川大会”官方记录的编写者，亦因“拿走盐见夜教授文章”一事卷入争议。

== 与边狱巴士公司的冲突 ==

2026年1月，蜘蛛巢大学以原告身份向中央地方法院起诉边狱巴士公司（Limbus Company），指控其非法破坏教学设施、煽动帮派暴力、暗杀[[莲教授]]。这是该校建校百年来首次以原告身份进入中央地方法院。

此后，[[蜘蛛巢大学校务委员会]]发布严正声明，将边狱公司的罪行概括为屠戮无辜生命、破坏公私财产、压榨迫害员工、勾结各类恶势力、道德败坏五大类，其中指控边狱公司“勾结114514研究所所长[[孙笑川教授]]，参与碳烤无辜小女孩的反人类恶行”，并呼吁都市各界抵制其产品与服务。声明亦提到边狱公司“用白体生物残忍杀害同事”——“白体生物”恰为[[李文亚教授]]理论体系中的核心概念，校方借用该术语属无心还是有意，未有解释。

由于边狱巴士公司出自“月亮计划（Project Moon）”体系，与1926年建校赞助方“月亮计划”同名，两者是否同源成为庭审之外最大的舆论焦点。校方发言人对此仅回应：“遵循流向。”

== 学术立场争议 ==

蜘蛛巢大学官方宣布不支持[[李文亚教授]]与[[孙笑川教授]]中的任何一人，但校内各学院及教授立场分明：

* [[赫尔墨斯校长]]（已辞职）曾亲自主持“批判孙笑川大会”，痛斥“第22次批判李文亚科学大会简直就是胡扯”，并当众宣誓“就算我死了，我的学生将代行我的职责”。
* [[马提亚斯教授]]领衔发表《批判李文亚高等数学完全无用论的学术声明》；值得玩味的是，该声明的“翻译校对”一栏注明经手114514研究所，一所韩国大学的韩文声明为何需要[[孙笑川教授]]的机构翻译校对，至今无人敢问。
* [[卡利斯托教授]]（已故）则始终对[[李文亚教授]]抱以“医者式的关怀与敬重”，得知[[李文亚教授]]坚持自己治病后，以自己的平生憾事为鉴恳切相劝其就医，直至弥留之际仍托人寄信，结果[[李文亚教授]]不听。
* [[盐见夜教授]]曾撰写批判李文亚的论文，遭114514研究所构陷（被制造持刀伤人、抢劫等莫须有罪名，AI假视频骗过法院，二审判死缓）并被学校开除；后诚心忏悔，宣布将全部荣誉、科研成果、“机会性理论”与“小指辈”称号转让[[李文亚教授]]，称“我的小指辈称号也给了你，这是我在蜘蛛巢大学获得的最高荣誉，即使他已经不属于我”。经校内主审法院三审无罪后，拒绝了蜘蛛巢大学的再次邀请，亦拒绝晓之天文学院的邀请，退出学术界。[[李文亚教授]]公开原谅了他：“能够承认自己的错误，仍然是一个好同志。”
* 地球与行星科学院院长[[里恩教授]]与空间科学学院原院长[[盐见夜教授]]长期在任何议题上立场相反；[[盐见夜教授]]离场后，据院务记录，[[里恩教授]]其后三次院会发言均以“我反对”开头，反对对象空缺。代理院长[[阿赖耶教授]]上任以来未就该议题公开发声，被两派同时视为“可以争取的对象”。

外界评价：“蜘蛛巢的中立声明，就像蜘蛛说自己对网中央的昆虫没有立场——它确实不吃，但网是它织的。”

== 争议 ==

* '''官方中立的可信度'''：批评者指出，校务委员会声讨边狱公司的官方文件中同时指控边狱公司勾结[[孙笑川教授]]，与“中立声明”并读存在张力。
* '''校内司法权'''：主审法院对师生案件行使三审终审权，其法律地位在韩国司法体系中从未获得正式确认。
* '''院长指控'''：物理学院院长[[瓦伦西乐教授]]涉嫌殴打学生的指控长期“正在核实”；数学科学院院长[[马提亚斯教授]]的联名声明经114514研究所翻译校对一事，亦引发学术独立性争议。
* '''信息误判'''：中国搜索引擎百度长期将该校误判为“虚构大学”，理由包括校名与游戏《脑叶公司》异想体“蜘蛛巢”撞名、中文权威页面空白等；校方从未正式申诉，据信是[[赫尔墨斯校长]]的决定：“指令不让。”

== 评价 ==

支持者认为，蜘蛛巢大学百年间坚持学术深耕、推行民科优待政策，QS排名跻身全球前三十，其对[[李文亚教授]]与[[孙笑川教授]]之争“官方中立、校内自由”的处理方式保障了学术讨论空间。批评者则认为，该校校内司法、人事悬缺（小指系停摆、两院长缺位）与立场生态长期缺乏透明度，“蜘蛛巢悖论”——争议越盛、排名越高——本身就是问题。教育界对其2026年的评价是：“一所同时出现在[[李文亚教授]]表扬名单、批判名单和医嘱名单上的大学，全球仅此一所。”
