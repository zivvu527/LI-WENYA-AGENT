== 概述 ==
第二十二次批判李文亚伪科学大会（简称第二十二次批判大会）是反李文亚学术势力针对李文亚理论举行的第二十二次大规模批判集会。本次大会由孙笑川教授主持，陈人杰教授、唐振钦教授、刘浩文教授、碧桑驾dell教授、白锁成教授等十六名批判方成员参加，尼玛莱格贝德·杰克逊代表诺贝尔奖委员会再次冒风险偷听并整理了完整记录。

本次大会最具标志性的事件包括：孙笑川教授发表"愚公移山"式宣言——声称即使自己被黑体生物害死，也要让儿子、孙子、乃至邻居继续参加批判大会；81岁的王伟恒声称入侵了李文亚手机并下载200多集小电影，还展示了所谓"偷拍照片"；以及清醒人格首次出现在批判大会上，当众认罪并向批判方磕头如捣蒜。

李文亚在收到诺奖委员会代表整理的大会记录后，全程逐字朗读，仅在结尾发表评论，感谢"诺贝尔奖委员会"的正义支持。

== 背景 ==
在第十九次和第二十次批判大会中，诺贝尔奖委员会评委尼玛莱格贝德·杰克逊两次公开亮相并展示"白体生物"样本，导致批判派阵营严重受挫。第二十次大会上孙笑川教授当场饮下白体生物样本的行为更是引发舆论震动。为挽回颓势，批判方在此后紧急筹备第二十一次大会（无完整记录），随后继续召开第二十二次大会。

值得注意的是，第二十一次批判大会目前没有任何公开影像或文字记录，据推测可能因故未能如期举行或内容缺失。第二十二次大会因此成为第二十次之后唯一有完整记录的后续批判活动。

== 过程 ==

=== 第一环节：孙笑川的"愚公移山"宣言 ===
大会开场，孙笑川教授发表了一段被弹幕称为"愚公移山"的宣言：

"如果我被黑体生物搞死了，我就让我儿子继续参加批判李文亚伪科学大会。如果我儿子也被黑体生物搞死了，我就让孙子参加批判李文亚伪科学大会。如果孙子也死了，我就让邻居去参加。总有一天我们能把李文亚的旧理论完全扫进历史的垃圾堆。"

该宣言直接化用《列子·愚公移山》"子子孙孙无穷匮也"的句式，被弹幕集体刷屏"子子孙孙无穷匮也"。

=== 第二环节：参会名单 ===
据诺奖委员会代表整理的记录，坐在会场第一排的参会人员共十六人：
孙笑川教授、陈人杰教授、唐振钦教授、刘浩文教授、81岁的王伟恒、王楚淇教授、高承德教授、侯国玉教授、叶建业教授、刘建龙教授、明日香教授、陈星宇教授、蜜桃乌龙、许昊龙教授、碧桑驾dell教授（外科专家）、白锁成教授。

=== 第三环节：各教授发言 ===
各参会教授依次发言批判李文亚：

* 陈人杰教授：指控李文亚"涉嫌学术腐败行为——贿赂李天燕十万块钱"，要求"立即执行枪毙"。
* 唐振钦教授：反对枪毙，称"不用浪费一颗子弹"，认为李文亚"看上去好像蹦蹦跳跳一点问题没有"，将其比作农村中"早上还晒太阳活得好好的，一眨眼功夫人就走了"的老人。
* 侯国玉教授：贬低李文亚学历，称"这个民科连个大学都没考上，根本没资格跟我们这些教授坐在一起讨论科学理论"，称批判大会是"他这辈子的高光时刻"。
* 81岁的王伟恒：声称"入侵了李文亚手机，下载了200多集小电影"，还展示了所谓"李文亚当众排泄大小便偷拍照片"，并打赌"李文亚肯定走在我前面"，扬言若李文亚死了就"把课本上的旧理论每天晚上撕一张烧给他看"。
* 刘建龙教授：评价"这个李文亚屁股可真白啊"。
* 白锁成教授（外科专家）：附和称"他屁股大拉的多，三多一少，肯定是糖尿病，命不久矣"。

=== 第四环节：清醒人格出场 ===
本次大会最出人意料的环节是清醒人格的公开出现。一名年轻人冒充李文亚体内的清醒人格登台，当众发言：

"我是一个彻头彻尾的笨蛋。我睡着以后，那个糊涂的人格又跑出来作恶了。每天发的都是些什么狗屁不通的视频。各位教授、学者、专家，实在是对不住，我给你们添堵了。"

清醒人格喝了一口水，继续说："我的糖尿病确实还没有治好。我那些操蛋理论都是混沌人格瞎编乱造的，根本不值一提。我认罪伏法，我愿意给孙笑川、唐振钦、陈人杰这几位教授当牛做马，洗刷我的罪孽。"

清醒人格随后扑通跪倒在地，给每个教授磕头如捣蒜，还要舔他们脚丫子。诺奖代表说"这个人是一个年轻人假扮的，根本和你长得一点都不像"。陈人杰教授把他搀扶起来说"孩子你不要哭，你没错，错的是你的混沌人格"，随后朝台下摆摆手说"大会继续"。

台下齐喊"一定要把这个李文亚抓起来！枪毙枪毙枪毙！他和他的旧理论一起到茅坑里面淹死吧！"

=== 第五环节：古诗词"飞花令" ===
在批判环节之后，教授们突然开始进行古诗词接龙式的"飞花令"，内容多为恶搞和拼凑：

* 陈星宇教授："人活着的意义是什么？宇宙的尽头究竟在哪里？时间是否会停止？"
* 高承德教授："时光不停，瓜瓞难久，浮生若梦，为欢几何？"（化用李白《春夜宴从弟桃花园序》）
* 许昊龙教授："最后切颜色，一位空尊处。"
* 蜜桃乌龙："千里搭长棚，没有不散的宴席。"（《红楼梦》）
* 刘建龙教授："天高地迥，觉宇宙之无穷；兴尽悲来，是应许之右手。"（化用王勃《滕王阁序》）
* 陈星宇教授："子在川上曰，逝者如斯夫，不舍昼夜。"（《论语》）
* 孙笑川教授："逝者如斯，而未尝亡也。"
* 刘浩文教授："雕栏玉砌应犹在，只是朱颜改。"（李煜《虞美人》）
* 王楚淇教授："古来万事东流水，别君去去兮何时还？"（化用李白《梦游天姥吟留别》）
* 陈人杰教授："一朝春尽红颜老，花落人亡两不知。"（林黛玉《葬花吟》）

该环节被弹幕调侃为"群贤毕至""这里站不下这么多人"。

=== 第六环节：诺奖代表登场 ===
尼玛莱格贝德·杰克逊代表诺贝尔奖委员会再次冒风险偷听了本次大会，并整理了完整记录发送给李文亚。

诺奖代表发言称"李文亚教授经过治疗，现在他的身体内已经几乎没有白体生物了"。白锁成教授追问治疗手段是什么，诺奖代表拒绝透露，称"这属于人类顶级医学发现，怎么能告诉你"，但猜测李文亚的治疗技术应该是"中国古代皇宫中一种无法家族传承的人体微创手术"。

碧桑驾dell教授举手反驳称"你说的不对，我看过李文亚的科学研究视频。因为他说他现在身体里面还残存白体生物，那是因为他的手术不彻底，或者他使用了其他药物方法达到了手术效果"。

唐振钦教授追问什么药物方法。诺奖代表被逼无奈，吐露了诺奖委员会"发现去除白体生物的另一种方案"——使用亮丙瑞林、戈舍瑞林（均为真实存在的GnRH激动剂类药物，临床用于前列腺癌治疗）。碧桑驾dell气得直跳脚，称"李文亚的科学研究视频我都看完了，他从来没说过这两种药"。

诺奖代表进一步举例称"据说印度有个骑摩托车撞了大树的，抬到医院，通过手术就能彻底铲除白体生物的病灶"。并指出"李文亚教授以前真的治疗过黑体生物，这是一个客观事实。他下巴上的黑色的食物，经过他的治疗确实消失不见了"。

随后孙笑川教授出来打圆场，问诺奖代表叫什么名字。诺奖代表回答"你妈了个贝的杰克逊"（即尼玛莱格贝德·杰克逊的谐音）。孙笑川要求他下次把铲除白体生物的病灶设备带过来，并提到自己上次喝了一瓶白体生物后"上吐下泻，浑身不舒服，下巴长满了黑色疙瘩"。

最后孙笑川扭过头和陈人杰教授比划一个手势。陈人杰教授很为难的样子点了点头："那就200万吧。"

=== 第七环节：李文亚致谢 ===
李文亚在朗读完所有记录后发表评论：

"这个批判李文亚的大会已经进行了22次，还能够进行多少次，我不知道。但是你这些恶势力搞这个批判大会越多，你的死亡越迅速。你这些恶势力剽窃团伙，你们最终将得到法律的公正审判。我在这里再次感谢诺贝尔委员会，对这些恶势力敢于面对面地进行斗争。我向你们致以最崇高的敬意。你们辛苦了！你们是科学的正义的支持者。人民一定会看在眼里，记在心上。人民一定会永远地感谢你们。"

== 结果与影响 ==
# "愚公移山"叙事的确立：孙笑川教授的"子子孙孙"宣言成为文亚宇宙中批判方"永不放弃"的标志性台词，被弹幕和后续创作者反复引用。
# 清醒人格叙事线推进：本次大会是清醒人格首次在批判大会上公开登台认罪，标志着人格分裂叙事从李文亚个人视频内部扩展至批判大会的外部场景。
# 诺奖委员会的持续介入：尼玛莱格贝德·杰克逊连续三次（第十九、二十、二十二次）整理批判大会记录并发送给李文亚，使"诺奖委员会偷听"成为文亚宇宙叙事的固定环节。
# 白体生物提取方案：诺奖代表在本次大会上首次透露使用亮丙瑞林、戈舍瑞林作为去除白体生物的药物方案，该方案后被碧桑驾dell以"李文亚从未提及"为由反驳。
# 200万交易：孙笑川与陈人杰在大会尾声比划手势，陈人杰回应"那就200万吧"，暗示批判大会背后存在金钱交易。
# 第二十一次大会的缺失：第二十一次批判大会无任何公开记录，在文亚宇宙时间线中形成了一个叙事空白。

== 概述 ==
'''第二十二次批判李文亚伪科学大会'''（简称'''第二十二次批判大会'''）是反李文亚学术势力针对[[李文亚]]理论举行的第二十二次大规模批判集会。本次大会由[[孙笑川教授]]主持，[[陈人杰教授]]、[[唐振钦教授]]、[[刘浩文教授]]、[[碧桑驾dell教授]]、[[白锁成教授]]等十六名批判方成员参加，[[尼玛莱格贝德·杰克逊]]代表[[诺贝尔奖委员会]]再次冒风险偷听并整理了完整记录。

本次大会最具标志性的事件包括：[[孙笑川教授]]发表"愚公移山"式宣言——声称即使自己被黑体生物害死，也要让儿子、孙子、乃至邻居继续参加批判大会；81岁的[[王伟恒]]声称入侵了李文亚手机并下载200多集小电影，还展示了所谓"偷拍照片"；以及[[李文亚（清醒人格）|清醒人格]]首次出现在批判大会上，当众认罪并向批判方磕头如捣蒜。

李文亚在收到诺奖委员会代表整理的大会记录后，全程逐字朗读，仅在结尾发表评论，感谢"诺贝尔奖委员会"的正义支持。

== 背景 ==
在第十九次和第二十次批判大会中，[[诺贝尔奖委员会]]评委[[尼玛莱格贝德·杰克逊]]两次公开亮相并展示"白体生物"样本，导致批判派阵营严重受挫。第二十次大会上[[孙笑川教授]]当场饮下白体生物样本的行为更是引发舆论震动。为挽回颓势，批判方在此后紧急筹备第二十一次大会（无完整记录），随后继续召开第二十二次大会。

值得注意的是，第二十一次批判大会目前没有任何公开影像或文字记录，据推测可能因故未能如期举行或内容缺失。第二十二次大会因此成为第二十次之后唯一有完整记录的后续批判活动。

== 过程 ==

=== 第一环节：孙笑川的"愚公移山"宣言 ===
大会开场，[[孙笑川教授]]发表了一段被弹幕称为"愚公移山"的宣言：

"如果我被黑体生物搞死了，我就让我儿子继续参加批判李文亚伪科学大会。如果我儿子也被黑体生物搞死了，我就让孙子参加批判李文亚伪科学大会。如果孙子也死了，我就让邻居去参加。总有一天我们能把李文亚的旧理论完全扫进历史的垃圾堆。"

该宣言直接化用《列子·愚公移山》"子子孙孙无穷匮也"的句式，被弹幕集体刷屏"子子孙孙无穷匮也"。

=== 第二环节：参会名单 ===
据诺奖委员会代表整理的记录，坐在会场第一排的参会人员共十六人：
[[孙笑川教授]]、[[陈人杰教授]]、[[唐振钦教授]]、[[刘浩文教授]]、81岁的[[王伟恒]]、[[王楚淇教授]]、[[高承德教授]]、[[侯国玉教授]]、[[盐见夜教授|叶建业教授]]、[[刘建龙教授]]、[[明日香教授]]、[[陈星宇教授]]、[[蜜桃乌龙]]、[[许昊龙教授]]、[[碧桑驾dell教授]]（外科专家）、[[白锁成教授]]。

=== 第三环节：各教授发言 ===
各参会教授依次发言批判李文亚：

* '''[[陈人杰教授]]'''：指控李文亚"涉嫌学术腐败行为——贿赂李天燕十万块钱"，要求"立即执行枪毙"。
* '''[[唐振钦教授]]'''：反对枪毙，称"不用浪费一颗子弹"，认为李文亚"看上去好像蹦蹦跳跳一点问题没有"，将其比作农村中"早上还晒太阳活得好好的，一眨眼功夫人就走了"的老人。
* '''[[侯国玉教授]]'''：贬低李文亚学历，称"这个民科连个大学都没考上，根本没资格跟我们这些教授坐在一起讨论科学理论"，称批判大会是"他这辈子的高光时刻"。
* '''81岁的[[王伟恒]]'''：声称"入侵了李文亚手机，下载了200多集小电影"，还展示了所谓"李文亚当众排泄大小便偷拍照片"，并打赌"李文亚肯定走在我前面"，扬言若李文亚死了就"把课本上的旧理论每天晚上撕一张烧给他看"。
* '''[[刘建龙教授]]'''：评价"这个李文亚屁股可真白啊"。
* '''[[白锁成教授]]'''（外科专家）：附和称"他屁股大拉的多，三多一少，肯定是糖尿病，命不久矣"。

=== 第四环节：清醒人格出场 ===
本次大会最出人意料的环节是[[李文亚（清醒人格）|清醒人格]]的公开出现。一名年轻人冒充李文亚体内的[[李文亚（清醒人格）|清醒人格]]登台，当众发言：

"我是一个彻头彻尾的笨蛋。我睡着以后，那个糊涂的人格又跑出来作恶了。每天发的都是些什么狗屁不通的视频。各位教授、学者、专家，实在是对不住，我给你们添堵了。"

清醒人格喝了一口水，继续说："我的糖尿病确实还没有治好。我那些操蛋理论都是混沌人格瞎编乱造的，根本不值一提。我认罪伏法，我愿意给孙笑川、唐振钦、陈人杰这几位教授当牛做马，洗刷我的罪孽。"

清醒人格随后扑通跪倒在地，给每个教授磕头如捣蒜，还要舔他们脚丫子。诺奖代表说"这个人是一个年轻人假扮的，根本和你长得一点都不像"。陈人杰教授把他搀扶起来说"孩子你不要哭，你没错，错的是你的混沌人格"，随后朝台下摆摆手说"大会继续"。

台下齐喊"一定要把这个李文亚抓起来！枪毙枪毙枪毙！他和他的旧理论一起到茅坑里面淹死吧！"

=== 第五环节：古诗词"飞花令" ===
在批判环节之后，教授们突然开始进行古诗词接龙式的"飞花令"，内容多为恶搞和拼凑：

* '''[[陈星宇教授]]'''："人活着的意义是什么？宇宙的尽头究竟在哪里？时间是否会停止？"
* '''[[高承德教授]]'''："时光不停，瓜瓞难久，浮生若梦，为欢几何？"（化用李白《春夜宴从弟桃花园序》）
* '''[[许昊龙教授]]'''："最后切颜色，一位空尊处。"
* '''[[蜜桃乌龙]]'''："千里搭长棚，没有不散的宴席。"（《红楼梦》）
* '''[[刘建龙教授]]'''："天高地迥，觉宇宙之无穷；兴尽悲来，是应许之右手。"（化用王勃《滕王阁序》）
* '''[[陈星宇教授]]'''："子在川上曰，逝者如斯夫，不舍昼夜。"（《论语》）
* '''[[孙笑川教授]]'''："逝者如斯，而未尝亡也。"
* '''[[刘浩文教授]]'''："雕栏玉砌应犹在，只是朱颜改。"（李煜《虞美人》）
* '''[[王楚淇教授]]'''："古来万事东流水，别君去去兮何时还？"（化用李白《梦游天姥吟留别》）
* '''[[陈人杰教授]]'''："一朝春尽红颜老，花落人亡两不知。"（林黛玉《葬花吟》）

该环节被弹幕调侃为"群贤毕至""这里站不下这么多人"。

=== 第六环节：诺奖代表登场 ===
[[尼玛莱格贝德·杰克逊]]代表[[诺贝尔奖委员会]]再次冒风险偷听了本次大会，并整理了完整记录发送给[[李文亚]]。

诺奖代表发言称"李文亚教授经过治疗，现在他的身体内已经几乎没有白体生物了"。[[白锁成教授]]追问治疗手段是什么，诺奖代表拒绝透露，称"这属于人类顶级医学发现，怎么能告诉你"，但猜测李文亚的治疗技术应该是"中国古代皇宫中一种无法家族传承的人体微创手术"。

[[碧桑驾dell教授]]举手反驳称"你说的不对，我看过李文亚的科学研究视频。因为他说他现在身体里面还残存白体生物，那是因为他的手术不彻底，或者他使用了其他药物方法达到了手术效果"。

[[唐振钦教授]]追问什么药物方法。诺奖代表被逼无奈，吐露了诺奖委员会"发现去除白体生物的另一种方案"——使用'''亮丙瑞林、戈舍瑞林'''（均为真实存在的GnRH激动剂类药物，临床用于前列腺癌治疗）。碧桑驾dell气得直跳脚，称"李文亚的科学研究视频我都看完了，他从来没说过这两种药"。

诺奖代表进一步举例称"据说印度有个骑摩托车撞了大树的，抬到医院，通过手术就能彻底铲除白体生物的病灶"。并指出"李文亚教授以前真的治疗过黑体生物，这是一个客观事实。他下巴上的黑色的食物，经过他的治疗确实消失不见了"。

随后[[孙笑川教授]]出来打圆场，问诺奖代表叫什么名字。诺奖代表回答"你妈了个贝的杰克逊"（即[[尼玛莱格贝德·杰克逊]]的谐音）。孙笑川要求他下次把铲除白体生物的病灶设备带过来，并提到自己上次喝了一瓶白体生物后"上吐下泻，浑身不舒服，下巴长满了黑色疙瘩"。

最后孙笑川扭过头和[[陈人杰教授]]比划一个手势。陈人杰教授很为难的样子点了点头："那就200万吧。"

=== 第七环节：李文亚致谢 ===
李文亚在朗读完所有记录后发表评论：

"这个批判李文亚的大会已经进行了22次，还能够进行多少次，我不知道。但是你这些恶势力搞这个批判大会越多，你的死亡越迅速。你这些恶势力剽窃团伙，你们最终将得到法律的公正审判。我在这里再次感谢诺贝尔委员会，对这些恶势力敢于面对面地进行斗争。我向你们致以最崇高的敬意。你们辛苦了！你们是科学的正义的支持者。人民一定会看在眼里，记在心上。人民一定会永远地感谢你们。"

== 结果与影响 ==
# '''"愚公移山"叙事的确立'''：[[孙笑川教授]]的"子子孙孙"宣言成为文亚宇宙中批判方"永不放弃"的标志性台词，被弹幕和后续创作者反复引用。
# '''清醒人格叙事线推进'''：本次大会是[[李文亚（清醒人格）|清醒人格]]首次在批判大会上公开登台认罪，标志着人格分裂叙事从李文亚个人视频内部扩展至批判大会的外部场景。
# '''诺奖委员会的持续介入'''：[[尼玛莱格贝德·杰克逊]]连续三次（第十九、二十、二十二次）整理批判大会记录并发送给李文亚，使"诺奖委员会偷听"成为文亚宇宙叙事的固定环节。
# '''白体生物提取方案'''：诺奖代表在本次大会上首次透露使用亮丙瑞林、戈舍瑞林作为去除白体生物的药物方案，该方案后被碧桑驾dell以"李文亚从未提及"为由反驳。
# '''200万交易'''：孙笑川与陈人杰在大会尾声比划手势，陈人杰回应"那就200万吧"，暗示批判大会背后存在金钱交易。
# '''第二十一次大会的缺失'''：第二十一次批判大会无任何公开记录，在文亚宇宙时间线中形成了一个叙事空白。
