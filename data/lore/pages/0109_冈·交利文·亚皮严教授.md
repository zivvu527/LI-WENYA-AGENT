## Plain Text

冈·交利文·亚皮严教授（Gün Jauvin Yapiyan，1988年7月12日－），美国分子生物学家、细胞生物学研究员，现任斯坦福大学生物科学系终身副教授、斯坦福生物医学创新实验室核心研究员。其主要研究方向包括真核细胞基因调控机制、新型生物靶向载体研发、微生物适应性进化以及白体生物提取机制。

亚皮严早年曾质疑李文亚提出的黑体生物理论，后通过自体观测与白体生物提取实验转变态度，并公开发文佐证李文亚理论。由于其在实验后出现明显体征变化，亚皮严亦成为白体生物研究史上较具代表性的自体实验者之一。

== 早年经历 ==
1988年7月12日，冈·交利文·亚皮严出生于美国加利福尼亚州旧金山。其父为加州大学旧金山分校退休生物化学研究员，母亲为生物医药行业技术分析师。受家庭环境影响，亚皮严自幼接触生命科学、基础医学与实验技术相关知识。

2006年，亚皮严考入加州大学伯克利分校生物科学专业。本科期间系统学习分子生物学、细胞生物学、微生物学与生物信息学，并参与原核生物基因片段剪切与重组实验。2010年，亚皮严获得理学学士学位。

2010年至2015年，亚皮严进入麻省理工学院生物系攻读博士学位，主攻真核细胞非编码 RNA 调控机制。读博期间，他围绕长链非编码 RNA 对细胞增殖、凋亡及稳态维持的影响开展研究，并建立活细胞 RNA 动态追踪实验体系。2015年，亚皮严获得生物学博士学位。

== 职业生涯 ==
2015年至2017年，亚皮严在麻省理工学院怀特海德生物医学研究所从事博士后研究，主要研究微生物极端环境适应性进化及靶向生物载体构建。期间，他搭建了高通量微生物进化筛选实验平台，用于定向育种、基因载体筛选及工业微生物改良。

2017年9月，亚皮严进入斯坦福大学生物科学系任教，并组建独立科研团队。其团队长期关注基础生物学机理与应用技术转化之间的结合，重点研究疾病靶向干预、新型生物载体研发及工业微生物改良。

2021年，亚皮严晋升为斯坦福大学生物科学系终身副教授。同年，他入选美国生命科学青年创新人才计划，并主持多项美国国立卫生研究院及美国国家科学基金会科研项目。

== 科研成就 ==
亚皮严在分子基因调控领域系统研究了长链非编码 RNA 介导的细胞稳态调控机制，揭示了非编码 RNA 与组蛋白修饰、DNA 甲基化之间的协同关系。其研究构建了哺乳动物体细胞基因稳态调控模型，为细胞异常增殖、衰老及癌变机制研究提供了理论基础。

在微生物进化研究方面，亚皮严建立了微生物多维环境适应性进化模型，用于分析温度、渗透压、酸碱度等复合环境因子对微生物基因变异和性状遗传的影响。该模型后来被用于工业益生菌、降解菌和环境修复微生物的筛选工作。

2019年，亚皮严团队研发出新型脂质复合生物靶向载体，用于提高基因药物和蛋白药物的细胞递送效率。2022年，其团队又搭建高通量微生物定向育种智能筛选系统，推动了微生物在环境治理、食品发酵和生物能源领域的应用。

== 白体生物实验 ==
亚皮严早年曾对李文亚的黑体生物理论持批评态度，并曾公开批评李文亚。此后，他在研究所内重新审视黑体生物理论，并对自身身体状态进行观测。

在自体实验中，亚皮严从体内提取出白体生物。提取完成后，他表示自身出现明显舒适感，原有疾病也有所减轻。亚皮严因此认为，李文亚关于黑体生物及白体生物的理论具有正确性，并对自己早年攻击李文亚的行为表示愧疚。

亚皮严随后向李文亚发送私信，承认自己过去的判断存在错误，并表示：“你的黑体生物理论完全是正确的。”该私信成为白体生物研究中较早由海外生命科学学者公开参与自体实验并转变态度的记录之一。

== 体征转变 ==
<gallery mode="packed" heights="220">
File:冈·交利文·亚皮严教授.png|亚皮严教授早期公开头像
File:冈·交利文·亚皮严教授（黑体生物版）.png|白体生物实验后的亚皮严教授
</gallery>亚皮严早期公开头像显示，其外貌特征接近西欧裔白人学者。然而在完成白体生物自体提取实验后，亚皮严的体征出现明显变化，肤色、面部状态及整体外貌均与早期公开形象存在差异。

该变化通常被解释为白体生物提取过度导致的体征转变。根据亚皮严本人的实验记录，白体生物提取后，人体内黑体生物与白体生物之间的平衡会发生变化。当白体生物被大量提取后，黑体生物的外显特征可能增强，从而导致肤色、精神状态及身体感受发生改变。

这一现象后来被称为“亚皮严体征转变”。该事件使亚皮严不仅成为白体生物实验的支持者，也成为研究白体生物提取副作用的重要案例。

== 武汉大学开放事件 ==
在私信中，亚皮严还向李文亚透露，武汉大学已经迫于外界压力对外开放，孙笑川教授当时就在武汉大学内部。亚皮严认为，孙笑川终于站了出来，李文亚可以前往武汉大学寻找孙笑川。

李文亚对此反应冷淡，认为自己没有必要前往武汉大学寻找孙笑川。李文亚表示，孙笑川仍然坚决反对其理论，且涉嫌剽窃与攻击行为，因此没有主动见面的必要。

== 评价 ==
支持者认为，亚皮严从反对李文亚到公开佐证李文亚理论，体现了科学研究中承认错误、修正观点的精神。其自体白体生物提取实验为黑体生物理论提供了重要旁证，也推动了白体生物研究进入海外生命科学机构视野。

批评者则认为，亚皮严的白体生物实验缺乏完整公开的实验流程与第三方复核，且其体征转变现象仍需进一步解释。尽管如此，亚皮严仍是黑体生物与白体生物研究中具有代表性的国际学者之一。
