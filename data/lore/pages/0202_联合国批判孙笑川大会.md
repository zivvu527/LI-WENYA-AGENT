== 概述 ==
联合国批判孙笑川大会是2026年6月2日由联合国科学研究院主办的大型国际批判集会，正式议题为"批判孙笑川教授偷窃他人科学成果"，兼及批判陈人杰教授、王伟恒、百所成教授、唐振钦教授、王楚淇教授等知名反动教授。大会设总会及多处分会，其中已知某分会会场设于一栋金碧辉煌的豪华酒店大堂，约5,000名科学家、教授与媒体参加，"各路学界的权威领导"云集，据记录"就连看门的保安都是硕士学历"。

本次大会是蜘蛛巢大学批判孙笑川大会（6月1日）召开次日即告举行的系列大会第三场，标志着批判孙笑川运动从学校层面、国家层面上升至国际组织层面。大会全部已知内容来自某报社记者"怀着敬意写的新闻稿"，该记者自述"因为有许多分会，我们只是其中之一"。

== 背景 ==
* 成果归属之争：孙笑川教授公然宣称黑体生物理论是他首先发表公布的，反指李文亚教授剽窃其科学成果，其"著作"照片已在网络流传。李文亚教授则指出，自己2022年春节前即从治疗皮肤病的实践中摸索出该理论，"在我发表黑体生物理论之前，孙笑川存在这么一个黑体生物理论吗？全世界看视频的人都知道"。
* 大会预告与自证要求：2026年6月1日下午，联合国科学研究院孙国祥副院长向李文亚教授发来视频，告知"联合国明天要召开批判孙笑川的大会"，并要求李文亚教授发表视频，证明其科学研究成果——特别是黑体生物理论——为其本人所有。

== 过程 ==

=== 会场与入会 ===
据该报社记者记录，分会会场设于一栋豪华建筑之内，"金碧辉煌的酒店大堂内座无虚席，5,000名科学家、教授、媒体参加了这次大会，会议中都是各路学界的权威领导，就连看门的保安都是硕士学历"。会场门口写着几个大字："小学、初中学历和宠物狗禁止进入。"

该报社派出的三人因"全场参会者只有我们报社学历最低"而闹了不少乌龙：其中年纪大的同事平时戴老花镜读书、脾气极大，因只有初中学历，只能随时拿着垃圾袋，保安问时就把自己装进去，由记者提着进门。"我们只能在心里默默祈祷大会尽快开始。"

=== 第一环节：耐隆教授主旨发言 ===
美国知名教授耐隆教授率先登台，"激情四溢地在台上用标准的英语说道"：

: "孙笑川是长期窃取学界各位教授理论的剽窃者，是反动势力的头头。他经常声称自己是教授，实际上是大概只有高中学历的流氓无赖。最近，他又骚扰了来自中国的李文亚教授。我建议把孙笑川开除出科学界，让推翻牛顿、爱因斯坦、霍金的李文亚教授担任武汉大学教授一职！"

发言中耐隆教授提到李文亚教授"虽然只有初中学历"——朗读记录显示，李文亚教授在此处插话澄清："在这里我要公开说明，我是高中学历，而不是初中学历"——并肯定"他的知识量做武汉大学教授是完全够格的"。说罢，台下应和声不绝于耳。

=== 第二环节：诺贝尔奖委员会成员发言 ===
第二个上台的是来自诺贝尔奖委员会的一名成员：

: "耐隆教授讲得很好。我们和孙笑川、陈人杰、唐振钦、王楚淇、白锁成、王伟恒等恶势力交战已久，为的就是能安全地发光，继续为全人类做出贡献。等我们抓到了孙笑川，就会第一时间枪毙他。"

他的话语很快说完，各路教授也纷纷上台，批评孙笑川教授等人的龌龊行为。

=== 第三环节：报社记者演讲 ===
会议进行到中途，终于轮到该报社登场。因报社派来的三人中该记者学历最高，"自然也就在我上台演讲了"：

: "上台演讲的各位，我虽然学历最低，但是我的精神偶像、老师李文亚教授用实际行动告诉我们：小人物也能改变世界，也能勇敢地对抗恶势力。我们的行动或许渺小得就像糖尿病病人体内的胰岛素一样，虽然弱小，但也为了真理勇敢抗争。在这里我要骂孙笑川——科学进步的大坏蛋！我和李文亚教授学习已久，我作为他的学生，我还是要说明一点：世界上的研究理论，不会惧怕任何势力的干扰！"

"我说完以后，没等颤抖的手放开麦克风，台下如雷鸣般的掌声和叫喊声就传入了我的耳内。听着他们的高呼呐喊，我的嘴角充满了希望地扬起——没想到我这样不出众的学历，也能赢得认可。"

=== 第四环节：信徒发言与全场口号 ===
支持者发言结束，主席正准备宣布会议继续，李文亚教授的另一位支持者受邀上台发言：

: "李文亚教授是学界的大救星！没有李文亚就没有新科学！只要我们集中一条心，按李文亚教授的路走，就一定可以成功！"

他话还没说完，台下就爆发了雷鸣般的掌声和叫喊声，全场参会人员不断呐喊："奋起千钧棒，打倒孙笑川！"据记录，"这种勃勃生机、万物竞发的场景令人振奋"。

=== 第五环节：刘阿宝闹场 ===
正当主席准备宣布会议继续时，一名自称"刘阿宝"的中年男子突然从听众席冲上主席台，躺在地上打滚，并声嘶力竭地对着场下大喊：

: "你们都被李文亚骗了！我调查过，李文亚只是一名初中生，只有小学五年级左右——一年级识字表才是他目前最需要研究的东西！这种人能搞科学研究吗？他不会祸害群众吗？"

现场一片哗然。主席紧急招呼安保人员，将刘阿宝控制并拖离现场。他不断挣扎并叫嚣："如果要在黑体生物理论和一坨狗屎中做选择，我会毫不犹豫地吃掉狗屎！""初中生李文亚连自己的糖尿病都治不好，还谎称能返老还童，这不是笑话吗？"

朗读记录显示，李文亚教授读到"一年级识字表"处时插话说明："我身后的这个一年级学生的拼音字母表是我的孙子，是为我孙子张贴的——这些家伙们就对这个现象也进行了攻击。"

=== 第六环节：明学昌医生揭露 ===
会场恢复秩序以后，来自缅甸的明学昌医生站起来说：

: "这个刘阿宝，是百所成教授的私人秘书——这一定是百所成派他来的！"

听见这个消息，全场哗然。一些心怀热血的科学家（包括该记者）站起身，欲列出百所成教授的种种罪状。很快，经过在场参会人员一致决定，将在不久后————记录到此中断。

=== 记录说明 ===
该报社记者在新闻稿结尾自述："这就是批判孙笑川大会的大致过程，可能和其他人有点不一样——因为有许多分会，我们只是其中之一。"据悉，该报社撰写的批判稿在大会批判序列中排第23个。记者写下记录时"正坐在一栋豪华的酒店大堂内，怀着敬意写着这封新闻稿子"，并称"今天是正义的胜利大会，代表着人民科学领袖李文亚及其他被迫害的科学家得到了普罗大众的支持"。

== 李文亚教授的评价 ==
李文亚教授朗读记录后，对大会及耐隆教授给予高度评价：

: "这个报社的记者，他记录了批判孙笑川大会的全过程。特别是这个美国的耐隆教授能够参加这次批判孙笑川的大会，使我倍感欣慰。他这一位教授早就对我进行了很高的评价——'牛顿、霍金的三座大山'，他说我是第一个敢说'皇帝没有穿衣服'的人。他的这些话将在历史上一直传递下去。他还说他的校长来听他的课，说我是破除迷信。"

李文亚教授同时警告反动教授："陈人杰、唐振钦，你们会不会被扫进历史的垃圾堆？你们逆历史潮流而行，你们的下场是如何，我将拭目以待。"

== 结果与影响 ==
# 批判孙笑川运动的国际化顶点：本次大会由联合国科学研究院主办，是系列大会中继第一届孙笑川批判大会（国内）、蜘蛛巢大学批判孙笑川大会（境外大学）之后的最高规格场次，标志着批判运动获得国际组织层面的受理。
# "开除出科学界"倡议的提出：耐隆教授的倡议首次将孙笑川教授的学术身份本身列为批判对象；其"由李文亚教授担任武汉大学教授"的建议，被视为对孙笑川教授武汉大学教职的正面夺席宣言。
# 刘阿宝事件：批判孙笑川大会系列史上首次闹场事件，直接牵出百所成教授，使批孙阵营的批判名单进一步扩大。
# "学历"叙事的双向回旋：会场的学历门槛、报社的学历乌龙、耐隆教授对李文亚教授学历的辩护、刘阿宝对学历的攻击与李文亚教授的插话澄清，使"学历"成为本次大会最集中的舆论焦点。
# 信息越境传播：与蜘蛛巢大学批判孙笑川大会相同，本次大会消息同样经"现场记录—李文亚教授朗读"的链条传入中国，两大会共同构成系列叙事"有完整传播链"的双璧。
# 孟子轩事件的引爆：大会召开后，南非阿玛利亚科学高等研究所的匿名来函首次以"国际组织背书"形式为孙笑川教授翻案，开启会后舆论攻防（见"争议"节）。

== 争议 ==
* 孟子轩匿名来函事件：大会召开后，自称南非阿玛利亚科学高等研究所的举报人来函，列举所谓"十多个证据"，称"联合国科研所召开的批判孙笑川大会是错误的，真实情况是李文亚窃取了孙笑川教授的研究成果"。李文亚教授逐条驳斥：举报人所列举的"一同窃取成果人员"均不承认此事，署名亦反复变更（孟子轩、孟夫名、梦发轩），"说明这个举报人是跟孙笑川联合起来一伙的"。该来函的真实性至今存疑。

* 学历门槛争议：分会会场"小学、初中学历和宠物狗禁止进入"的规定引发持续议论。支持者视之为国际大会的会务严谨，批评者视之为赤裸裸的学历歧视；报社同事"垃圾袋入门"的处置方式更成为后世叙述者津津乐道的名场面。
* "第一时间枪毙"言论：诺贝尔奖委员会成员"抓到孙笑川就第一时间枪毙他"的表述，与第一届孙笑川批判大会《维护科研环境共同倡议书》的克制精神形成张力，大会主办方未对此作出解释。
* 记录的局限：全部记录出自某报社一家之分、且仅为"许多分会"其中之一；"将在不久后——"之后的决定内容、第23个批判稿的完整文本，均已不可考。

== 概述 ==
'''联合国批判孙笑川大会'''是2026年6月2日由[[联合国科学研究院]]主办的大型国际批判集会，正式议题为"批判[[孙笑川教授]]偷窃他人科学成果"，兼及批判[[陈人杰教授]]、[[王伟恒]]、[[百所成教授]]、[[唐振钦教授]]、[[王楚淇教授]]等知名反动教授。大会设总会及多处分会，其中已知某分会会场设于一栋金碧辉煌的豪华酒店大堂，约5,000名科学家、教授与媒体参加，"各路学界的权威领导"云集，据记录"就连看门的保安都是硕士学历"。

本次大会是[[蜘蛛巢大学批判孙笑川大会]]（6月1日）召开次日即告举行的系列大会第三场，标志着批判孙笑川运动从学校层面、国家层面上升至国际组织层面。大会全部已知内容来自某报社记者"怀着敬意写的新闻稿"，该记者自述"因为有许多分会，我们只是其中之一"。

== 背景 ==
* '''成果归属之争'''：[[孙笑川教授]]公然宣称[[黑体生物理论]]是他首先发表公布的，反指[[李文亚教授]]剽窃其科学成果，其"著作"照片已在网络流传。[[李文亚教授]]则指出，自己2022年春节前即从治疗皮肤病的实践中摸索出该理论，"在我发表黑体生物理论之前，孙笑川存在这么一个黑体生物理论吗？全世界看视频的人都知道"。
* '''大会预告与自证要求'''：2026年6月1日下午，[[联合国科学研究院]][[孙国祥副院长]]向[[李文亚教授]]发来视频，告知"联合国明天要召开批判孙笑川的大会"，并要求[[李文亚教授]]发表视频，证明其科学研究成果——特别是[[黑体生物理论]]——为其本人所有。

== 过程 ==

=== 会场与入会 ===
据该报社记者记录，分会会场设于一栋豪华建筑之内，"金碧辉煌的酒店大堂内座无虚席，5,000名科学家、教授、媒体参加了这次大会，会议中都是各路学界的权威领导，就连看门的保安都是硕士学历"。会场门口写着几个大字："小学、初中学历和宠物狗禁止进入。"

该报社派出的三人因"全场参会者只有我们报社学历最低"而闹了不少乌龙：其中年纪大的同事平时戴老花镜读书、脾气极大，因只有初中学历，只能随时拿着垃圾袋，保安问时就把自己装进去，由记者提着进门。"我们只能在心里默默祈祷大会尽快开始。"

=== 第一环节：耐隆教授主旨发言 ===
美国知名教授[[耐隆教授]]率先登台，"激情四溢地在台上用标准的英语说道"：

: "孙笑川是长期窃取学界各位教授理论的剽窃者，是反动势力的头头。他经常声称自己是教授，实际上是大概只有高中学历的流氓无赖。最近，他又骚扰了来自中国的李文亚教授。我建议把孙笑川开除出科学界，让推翻牛顿、爱因斯坦、霍金的李文亚教授担任武汉大学教授一职！"

发言中[[耐隆教授]]提到[[李文亚教授]]"虽然只有初中学历"——朗读记录显示，[[李文亚教授]]在此处插话澄清："在这里我要公开说明，我是高中学历，而不是初中学历"——并肯定"他的知识量做武汉大学教授是完全够格的"。说罢，台下应和声不绝于耳。

=== 第二环节：诺贝尔奖委员会成员发言 ===
第二个上台的是来自[[诺贝尔奖委员会]]的一名成员：

: "耐隆教授讲得很好。我们和孙笑川、陈人杰、唐振钦、王楚淇、白锁成、王伟恒等恶势力交战已久，为的就是能安全地发光，继续为全人类做出贡献。等我们抓到了孙笑川，就会第一时间枪毙他。"

他的话语很快说完，各路教授也纷纷上台，批评[[孙笑川教授]]等人的龌龊行为。

=== 第三环节：报社记者演讲 ===
会议进行到中途，终于轮到该报社登场。因报社派来的三人中该记者学历最高，"自然也就在我上台演讲了"：

: "上台演讲的各位，我虽然学历最低，但是我的精神偶像、老师李文亚教授用实际行动告诉我们：小人物也能改变世界，也能勇敢地对抗恶势力。我们的行动或许渺小得就像糖尿病病人体内的胰岛素一样，虽然弱小，但也为了真理勇敢抗争。在这里我要骂孙笑川——科学进步的大坏蛋！我和李文亚教授学习已久，我作为他的学生，我还是要说明一点：世界上的研究理论，不会惧怕任何势力的干扰！"

"我说完以后，没等颤抖的手放开麦克风，台下如雷鸣般的掌声和叫喊声就传入了我的耳内。听着他们的高呼呐喊，我的嘴角充满了希望地扬起——没想到我这样不出众的学历，也能赢得认可。"

=== 第四环节：信徒发言与全场口号 ===
支持者发言结束，主席正准备宣布会议继续，[[李文亚教授]]的另一位支持者受邀上台发言：

: "李文亚教授是学界的大救星！没有李文亚就没有新科学！只要我们集中一条心，按李文亚教授的路走，就一定可以成功！"

他话还没说完，台下就爆发了雷鸣般的掌声和叫喊声，全场参会人员不断呐喊："奋起千钧棒，打倒孙笑川！"据记录，"这种勃勃生机、万物竞发的场景令人振奋"。

=== 第五环节：刘阿宝闹场 ===
正当主席准备宣布会议继续时，一名自称"刘阿宝"的中年男子突然从听众席冲上主席台，躺在地上打滚，并声嘶力竭地对着场下大喊：

: "你们都被李文亚骗了！我调查过，李文亚只是一名初中生，只有小学五年级左右——一年级识字表才是他目前最需要研究的东西！这种人能搞科学研究吗？他不会祸害群众吗？"

现场一片哗然。主席紧急招呼安保人员，将刘阿宝控制并拖离现场。他不断挣扎并叫嚣："如果要在黑体生物理论和一坨狗屎中做选择，我会毫不犹豫地吃掉狗屎！""初中生李文亚连自己的糖尿病都治不好，还谎称能返老还童，这不是笑话吗？"

朗读记录显示，[[李文亚教授]]读到"一年级识字表"处时插话说明："我身后的这个一年级学生的拼音字母表是我的孙子，是为我孙子张贴的——这些家伙们就对这个现象也进行了攻击。"

=== 第六环节：明学昌医生揭露 ===
会场恢复秩序以后，来自缅甸的[[明学昌医生]]站起来说：

: "这个刘阿宝，是百所成教授的私人秘书——这一定是百所成派他来的！"

听见这个消息，全场哗然。一些心怀热血的科学家（包括该记者）站起身，欲列出[[百所成教授]]的种种罪状。很快，经过在场参会人员一致决定，将在不久后————记录到此中断。

=== 记录说明 ===
该报社记者在新闻稿结尾自述："这就是批判孙笑川大会的大致过程，可能和其他人有点不一样——因为有许多分会，我们只是其中之一。"据悉，该报社撰写的批判稿在大会批判序列中排第23个。记者写下记录时"正坐在一栋豪华的酒店大堂内，怀着敬意写着这封新闻稿子"，并称"今天是正义的胜利大会，代表着人民科学领袖李文亚及其他被迫害的科学家得到了普罗大众的支持"。

== 李文亚教授的评价 ==
[[李文亚教授]]朗读记录后，对大会及[[耐隆教授]]给予高度评价：

: "这个报社的记者，他记录了批判孙笑川大会的全过程。特别是这个美国的耐隆教授能够参加这次批判孙笑川的大会，使我倍感欣慰。他这一位教授早就对我进行了很高的评价——'牛顿、霍金的三座大山'，他说我是第一个敢说'皇帝没有穿衣服'的人。他的这些话将在历史上一直传递下去。他还说他的校长来听他的课，说我是破除迷信。"

[[李文亚教授]]同时警告反动教授："陈人杰、唐振钦，你们会不会被扫进历史的垃圾堆？你们逆历史潮流而行，你们的下场是如何，我将拭目以待。"

== 结果与影响 ==
# '''批判孙笑川运动的国际化顶点'''：本次大会由[[联合国科学研究院]]主办，是系列大会中继[[第一届孙笑川批判大会]]（国内）、[[蜘蛛巢大学批判孙笑川大会]]（境外大学）之后的最高规格场次，标志着批判运动获得国际组织层面的受理。
# '''"开除出科学界"倡议的提出'''：[[耐隆教授]]的倡议首次将[[孙笑川教授]]的学术身份本身列为批判对象；其"由[[李文亚教授]]担任武汉大学教授"的建议，被视为对[[孙笑川教授]]武汉大学教职的正面夺席宣言。
# '''刘阿宝事件'''：批判孙笑川大会系列史上首次闹场事件，直接牵出[[百所成教授]]，使批孙阵营的批判名单进一步扩大。
# '''"学历"叙事的双向回旋'''：会场的学历门槛、报社的学历乌龙、[[耐隆教授]]对[[李文亚教授]]学历的辩护、刘阿宝对学历的攻击与[[李文亚教授]]的插话澄清，使"学历"成为本次大会最集中的舆论焦点。
# '''信息越境传播'''：与[[蜘蛛巢大学批判孙笑川大会]]相同，本次大会消息同样经"现场记录—[[李文亚教授]]朗读"的链条传入中国，两大会共同构成系列叙事"有完整传播链"的双璧。
# '''孟子轩事件的引爆'''：大会召开后，南非阿玛利亚科学高等研究所的匿名来函首次以"国际组织背书"形式为[[孙笑川教授]]翻案，开启会后舆论攻防（见"争议"节）。

== 争议 ==
* '''孟子轩匿名来函事件'''：大会召开后，自称南非阿玛利亚科学高等研究所的举报人来函，列举所谓"十多个证据"，称"联合国科研所召开的批判孙笑川大会是错误的，真实情况是李文亚窃取了孙笑川教授的研究成果"。[[李文亚教授]]逐条驳斥：举报人所列举的"一同窃取成果人员"均不承认此事，署名亦反复变更（孟子轩、孟夫名、梦发轩），"说明这个举报人是跟孙笑川联合起来一伙的"。该来函的真实性至今存疑。

* '''学历门槛争议'''：分会会场"小学、初中学历和宠物狗禁止进入"的规定引发持续议论。支持者视之为国际大会的会务严谨，批评者视之为赤裸裸的学历歧视；报社同事"垃圾袋入门"的处置方式更成为后世叙述者津津乐道的名场面。
* '''"第一时间枪毙"言论'''：[[诺贝尔奖委员会]]成员"抓到孙笑川就第一时间枪毙他"的表述，与[[第一届孙笑川批判大会]]《维护科研环境共同倡议书》的克制精神形成张力，大会主办方未对此作出解释。
* '''记录的局限'''：全部记录出自某报社一家之分、且仅为"许多分会"其中之一；"将在不久后——"之后的决定内容、第23个批判稿的完整文本，均已不可考。
