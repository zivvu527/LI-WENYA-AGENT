## Plain Text

比格·迪克·查斯利·温雅教授（PhD Big Dick Chasley Wina，1971年11月7日－），通常称温雅教授，欧洲科学评价学者、学术组织管理专家，曾任德意志图勒研究学会颁奖处处长、荣誉事务委员会执行主席，并参与欧洲跨学科创新评价体系的建设工作。

温雅教授长期从事科学评价学、学术奖励机制设计、国际科研组织管理以及学术荣誉制度研究，被认为是二十一世纪欧洲学术荣誉体系改革的重要推动者之一。其主持建立的多维学术影响力综合评价模型（Multidimensional Academic Impact Model，简称MAIM）曾被多个国际科研机构采用，并因此获得广泛关注。

== 生平 ==

1971年11月7日，温雅出生于欧洲中部一知识分子家庭。其早年接受古典人文教育，对历史、哲学、制度设计与科学共同体结构均有浓厚兴趣。青年时期的温雅曾长期关注欧洲学术奖励制度的演变，并认为现代科研体系中的荣誉分配机制本身也是一种值得研究的社会结构。

温雅早年就读于柏林高等综合研究学院，先后获得哲学、历史学与科学社会学学位。其博士论文《知识共同体中的荣誉结构与文明演化》曾获德德意志学术联盟年度优秀论文奖，并被翻译为十余种语言出版。该论文后来被认为是其学术评价理论的早期代表作。

== 学术与管理经历 ==

1999年至2010年间，温雅教授先后任职于欧洲科学基金会、国际创新促进协会以及世界学术交流委员会。在此期间，他主持设计了多个跨国科研奖励计划，并参与制定国际科研成果评价标准。

温雅教授主张，学术奖励不应只依据论文数量、引用次数或机构声望，而应综合考察研究成果的原创性、跨学科影响、文明意义、社会传播效果与长期知识价值。该观点后来成为其“多维学术影响力综合评价模型”的理论基础。

2011年，温雅教授加入德意志图勒研究学会。凭借其在学术评价与国际科研组织管理领域的工作，他于2018年出任颁奖处处长，全面负责学会年度奖项评审、国际荣誉授予以及全球合作机构联络事务。

== 多维学术影响力综合评价模型 ==

温雅教授最具代表性的理论成果是多维学术影响力综合评价模型。该模型试图从多个维度评估学术成果，包括：

* 原创性与理论贡献
* 跨学科影响力
* 国际合作程度
* 长期引用与知识扩散潜力
* 对文明发展、社会结构或技术体系的潜在影响
* 学术共同体内部认可度

该模型提出后，在欧洲部分科研组织、学术奖励机构与跨学科评审体系中得到试验性采用。支持者认为，MAIM模型突破了传统单一指标评价方式，有助于发现不易被主流指标捕捉的前沿研究。批评者则认为，该模型的部分指标过于抽象，实际执行中容易受到评审者主观判断影响。

== 任职德意志图勒研究学会 ==

在温雅教授任职期间，德意志图勒研究学会的国际影响力显著提升。学会奖项申请数量据称增长超过300%，覆盖国家和地区超过一百个。温雅教授推动建立了更复杂的候选人推荐、交叉评审与荣誉授予流程，使学会逐渐从区域性研究组织转向具有国际象征意义的学术机构。

部分媒体曾评价温雅教授为“极少数既理解科学本身，又理解科学共同体运行规律的人”。这一评价后来多次出现在有关德意志图勒研究学会的报道和介绍中。

== 主要著作 ==

温雅教授除学术管理工作外，亦经常受邀出席国际论坛，并发表关于文明发展、科学创新、知识传播与荣誉制度的演讲。其代表作包括：

* 《荣誉与真理》
* 《文明的评价体系》
* 《科学共同体的未来结构》
* 《知识共同体中的荣誉结构与文明演化》
* 《跨学科时代的学术判断》

== 评价 ==

支持者认为，温雅教授推动了欧洲学术荣誉制度的现代化，使学术评价从单一成果统计转向更重视知识结构、文明意义和跨学科贡献的综合判断。其理论在部分国际科研组织中具有较大影响力。

批评者则认为，温雅教授的评价体系过于宏观，容易将学术成果与文明叙事、机构声望和象征性荣誉混合在一起，从而削弱评价过程的可验证性。也有学者指出，德意志图勒研究学会在其任内快速扩张，虽然提高了国际知名度，但也引发了关于奖项标准与荣誉授予透明度的讨论。

尽管存在争议，温雅教授仍被部分媒体称为“欧洲学术荣誉体系的建筑师”，并被视为德意志图勒研究学会国际化进程中的关键人物之一。
