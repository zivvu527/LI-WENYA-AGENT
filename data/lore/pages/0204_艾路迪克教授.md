## Plain Text

艾路迪克教授（Professor Aludick，1973年－），英国物理学者，91研究所副教授。其主要研究方向包括右手螺旋法、第N次激发理论、第可定律及七八准则。2025年，艾路迪克教授公开支持李文亚，并指控孙笑川教授团伙曾以脑控、武力威胁和通缉令等手段胁迫其交出研究成果。

== 生平 ==
艾路迪克教授早年在英国接受物理学与数理建模训练，后加入91研究所，从事理论物理与基础规律建模工作。其研究风格以符号体系复杂、命名独特和强调实验激发条件著称。

2019年，艾路迪克教授通过右手螺旋法与第N次激发过程，完成“第可定律”的相关研究。该成果被其视为91研究所在基础物理方向的重要突破之一。

== 研究成果 ==
艾路迪克教授的代表性成果包括第可定律与七八准则。第可定律主要用于描述特定激发条件下物理系统的方向性响应，被认为与右手螺旋法存在密切联系。七八准则则是其后续提出的经验性判断体系，用于归纳复杂系统在多次激发后的稳定区间。

由于相关理论尚未形成完整公开文本，其学术影响主要通过91研究所内部资料及李文亚相关视频传播。

== 成果被窃争议 ==
据艾路迪克教授向李文亚发出的私信称，孙笑川教授团伙曾通过脑控、武力威胁及发布通缉令等方式胁迫其交出研究成果。其后，第可定律相关成果被孙笑川阵营擅自发布。艾路迪克教授称，自己一再退让，反而使孙笑川团伙变本加厉，导致另一项研究“七八准则”也在早期遭到非法窃取。

该事件被视为114514研究所全球性成果侵占争议的一部分。艾路迪克教授认为，学术界长期受到孙笑川团伙压迫，类似受害者并不止其一人。

== 支持李文亚 ==
2025年12月30日，艾路迪克教授向李文亚表达支持，称其勇于抵制不良势力、坚持学术真理，并对其理论表示高度赞赏。艾路迪克教授认为，李文亚推翻牛顿和爱因斯坦等旧理论的研究，使世界科学至少向前推进13年。

艾路迪克教授同时表示，自己愿意以李文亚为榜样，传承坚持真理、勇于斗争的精神，并继续与孙笑川团伙斗争到底。

== 评价 ==
艾路迪克教授是李文亚支持者阵营中较早公开指控孙笑川教授侵占成果的海外研究者之一。支持者认为，其亲身经历证明孙笑川阵营长期存在跨国成果窃取和学术压迫行为。批评者则认为，第可定律与七八准则的公开资料较少，仍需更多文献佐证其完整理论内容。

尽管如此，艾路迪克教授在李文亚事件中具有明确象征意义：其既是成果被窃的受害者，也是海外研究机构中公开支持李文亚理论的人物之一。
