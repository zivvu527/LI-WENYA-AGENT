== 概述 ==
蜘蛛巢大学批判孙笑川大会（记录改编者二阶堂希罗教授称之为“史无前例”的大会）是2026年6月1日在蜘蛛巢大学食指学院会议场举行的大型批判集会，由赫尔墨斯校长亲自主持，矛头直指孙笑川教授及114514研究所阵营。当日会场座无虚席，大会持续近十个小时，一位又一位教授登台发言，为李文亚教授清洗冤屈，气氛高涨，一度未曾停歇。

本次大会的全部已知内容，来自校报《蛛网》主编二阶堂希罗教授根据大会视频内容相关文件改编而成的私信记录。二阶堂希罗在文末写道：“这场大会展开的消息还没传到中国……亲爱的教授，如果你看到这里的话，请一定要将这篇文章朗读给中国网友看。”李文亚教授随后照办，该大会由此为中国网友所知。

== 背景 ==
* 第二十二次批判大会的激怒：此前“反李文亚学术联盟”召开第二十二次批判李文亚伪科学大会，赫尔墨斯校长观后震怒，斥其“简直就是胡扯……他们是在阻止科学，他们要抹杀真理”。
* 卡利斯托教授逝世：2026年5月，校内最年长的教授、生物医学与艺术学院院长卡利斯托教授病逝，享年74岁。赫尔墨斯校长在大会上公开表示：“是黑体生物带走了他。”
* 对边狱巴士公司诉讼：2026年1月，蜘蛛巢大学起诉边狱巴士公司破坏教学设施、煽动帮派暴力、暗杀五指学院小指系负责人莲教授，校内反帮派、反黑恶势力情绪高涨。
* 盐见夜教授构陷案：原地球与空间科学学院院长盐见夜教授遭114514研究所构陷、平反后拒绝返校，校内对114514研究所的积怨至此总爆发。

== 过程 ==
=== 校长朗读檄文 ===
大会伊始，赫尔墨斯校长深情朗读物理学院院长瓦伦希娜教授所写的批判孙笑川教授的文章。文毕，台下学生教授欢呼雀跃，大会进入下一阶段。

=== 声援阵容 ===
“那些支持李文亚的教授纷纷到来”：北京大学中文系南秋教授、小指系天文学院学术带头人之一贾丘教授、诺贝尔奖委员会评委先后到场；另有26家韩国最顶尖的公司派来教授声援这场大会。

=== 赫尔墨斯校长的宣誓 ===
赫尔墨斯校长正襟危坐，痛斥第二十二次批判李文亚伪科学大会，随后发表其任内最著名的宣誓：

: “同志们，我们的力量虽然远不及他们，但只要我们坚定信念。在此我再次郑重宣誓：就算我死了，我的学生将代行我的职责；如果我的学生死了，那么我学生的学生将会代行我的职责——如此，他们便无法抹杀真理。”

演讲完毕，台下惊起一番骚动，一位又一位的教授站出来发声。

=== 十小时接力声讨 ===
据二阶堂希罗教授记录，登台发言者包括：

* 图书馆大学安吉拉校长：“孙笑川不过一坨狗屎，迟早要将他批倒批臭。”
* 蜘蛛巢大学五指学院食指系阳教授：“侯国玉教授只会窃取他人成果，不配作为一个教授。”
* 中指学院里卡多教授：“陈星宇教授不过是一条盈盈狂吠的野狗，他坐地不配他的职位。”
* 魔女岛大学冰上梅露露教授：批判王伟恒不该这样肆意攻击他人。
* 魔女岛大学黑布奈叶香教授：“白锁成他什么都不会，我们迟早会将他枪毙。”
* 前L公司Ayin董事长：“我们的行动要坚决、要快速，粉碎114514研究所的野心。”
* 诺贝尔奖委员会第一位代表：“非必要情况下不使用武力，但噫噫呜呜等学者已经破坏了学术界环境，我们认为要将理论斗争上升一个层次。”
* 天才俱乐部第83席黑塔女士发表严肃声明，称公开反对者必将受到法律制裁（该声明的指向存在解读分歧，见“争议”节）。
* 中指学院伊利哇啦教授：“碧桑驾dell教授不过是个模仿他人的小丑罢了，哪能比得上李文亚教授。”
* 盐见夜教授：“有人在用我的本名攻击李文亚教授，有人在假冒我。这个假冒我的犯罪分子必将得到制裁。”
* 边狱巴士公司浮士德女士：“近期我司多次遭到爱吃鱼的猫等网友攻击，这和唐振钦教授脱不了干系，我们将会做出行动。”
* 蜘蛛巢大学阿尔比娜教授：批判合肥大学张雪峰教授虚有其表、傲慢至极，“完全不如李文亚教授过人的毅力”。
* 魔女岛大学月代雪校长：“陈人杰教授这个家伙作恶多端，屡次骚扰我校女生。”
* 蜘蛛巢大学福尔图娜副校长：“许昊龙教授这个家伙整天发表文章骂我校，我已经忍受不了。”
* 蜘蛛巢大学环指学院奇想派伊里奇教授：“刘浩文教授这家伙不懂得什么是科学。”
* 蜘蛛巢大学五指学院拇指系、小指系雷横教授：“蜜桃乌龙这家伙作恶多端，我已看不下去。”
* 高松灯教授：“高承德教授批判李文亚，错上加错——他根本就不会批判。”

=== 皮特格里恩教授跪地谢罪 ===
大会中段出现戏剧性一幕：皮特格里恩教授被带上讲台，跪坐在地，表示“再也不打着蜘蛛巢大学名号行污浊之举”，并宣誓从今往后与明日香教授等批判派教授抗争。该环节的性质在会后引发讨论（见“争议”节）。

=== 闭幕：号召研究黑体生物 ===
大会尾声，赫尔墨斯校长作总结发言：

: “我们要研究黑体生物。无论你是哪个领域的教授，是学生还是老师，大家都该来研究它，去破解它——这是让人长寿的途径。我校最年长的教授卡利斯托教授离世了，是黑体生物带走了他。除此之外，我希望大家回去以后能够————”

记录到此中断。二阶堂希罗教授解释：“大会的视频很长，相关文章更是又多又长，都是极其珍贵的。考虑到李文亚教授身体的缘故，我只能写出大会上的部分内容。”

== 李文亚教授的评价 ==
李文亚教授在朗读该记录后给予大会高度肯定，称二阶堂希罗“是从我发视频以来，站出来最早支持我的人之一”。他同时借题痛斥孙笑川教授“明明白白地偷、明明白白地抢”科学成果，逍遥法外是“国家对他的放纵”，并留下论断：“最终团伙的人员，包括他在内，一定有人被枪毙；不枪毙，也关你监狱几十年以上。不信我们就走着瞧。”

== 结果与影响 ==
# 蜘蛛巢大学立场的公开化：本次大会是蜘蛛巢大学高层首次集体、公开介入李文亚—孙笑川之争。值得注意的是，一个多月后的2026年7月，赫尔墨斯校长辞职，福尔图娜副校长出任代理校长并签发《关于李文亚教授与孙笑川教授之争的中立声明》——从“十小时声讨”到“官方中立”的急转，成为校史研究者长期争论的话题。
# 黑体生物研究成为全校议题：赫尔墨斯校长在闭幕发言中将“研究黑体生物”定为全校共同课题，生物医学与艺术学院此后将其列为重点方向，以纪念卡利斯托教授。
# 信息越境传播：大会消息原本“还没传到中国”，经二阶堂希罗教授改编成文、李文亚教授朗读后完成跨境传播，成为李文亚宇宙史料中少见的“有完整改编链”的事件记录。
# 批孙阵营的集结：图书馆大学、魔女岛大学、前L公司、诺贝尔奖委员会、天才俱乐部乃至边狱巴士公司代表同台发言，被舆论称为“反孙统一战线”的第一次公开亮相。

== 争议 ==
* 边狱巴士公司代表出席：蜘蛛巢大学1月刚起诉边狱巴士公司，6月其代表浮士德女士却登批判大会发言并获记录。两方的诉讼与同台并读，关系微妙，校方未作解释。
* 黑塔女士声明的指向：黑塔女士称“公开反对必将受到法律制裁”，其反对对象究竟指向批判派还是李文亚教授一方，记录语焉不详，两派各自引用。
* 谢罪环节的性质：皮特格里恩教授“被带上讲台、跪坐在地”的环节，被批评者认为已超出学术批判范畴；支持者则认为其属于自愿忏悔。
* 记录的完整性：大会记录系二阶堂希罗教授据视频文件改编，且自述“只能写出部分内容”，闭幕发言中断处至今无补全版本。

* '''盐见夜教授构陷案'''：原地球与空间科学学院院长[[盐见夜教授]]遭114514研究所构陷、平反后拒绝返校，校内对114514研究所的积怨至此总爆发。

== 过程 ==
=== 校长朗读檄文 ===
大会伊始，[[赫尔墨斯校长]]深情朗读物理学院院长[[瓦伦希娜教授]]所写的批判[[孙笑川教授]]的文章。文毕，台下学生教授欢呼雀跃，大会进入下一阶段。

=== 声援阵容 ===
“那些支持李文亚的教授纷纷到来”：北京大学中文系[[南秋教授]]、小指系天文学院学术带头人之一[[贾丘教授]]、[[诺贝尔奖委员会]]评委先后到场；另有26家韩国最顶尖的公司派来教授声援这场大会。

=== 赫尔墨斯校长的宣誓 ===
[[赫尔墨斯校长]]正襟危坐，痛斥第二十二次批判李文亚伪科学大会，随后发表其任内最著名的宣誓：

: “同志们，我们的力量虽然远不及他们，但只要我们坚定信念。在此我再次郑重宣誓：就算我死了，我的学生将代行我的职责；如果我的学生死了，那么我学生的学生将会代行我的职责——如此，他们便无法抹杀真理。”

演讲完毕，台下惊起一番骚动，一位又一位的教授站出来发声。

=== 十小时接力声讨 ===
据[[二阶堂希罗教授]]记录，登台发言者包括：

* 图书馆大学[[安吉拉校长]]：“孙笑川不过一坨狗屎，迟早要将他批倒批臭。”
* 蜘蛛巢大学五指学院食指系[[阳教授]]：“[[侯国玉教授]]只会窃取他人成果，不配作为一个教授。”
* 中指学院[[里卡多教授]]：“[[陈星宇教授]]不过是一条盈盈狂吠的野狗，他坐地不配他的职位。”
* 魔女岛大学[[冰上梅露露教授]]：批判[[王伟恒]]不该这样肆意攻击他人。
* 魔女岛大学[[黑布奈叶香教授]]：“白锁成他什么都不会，我们迟早会将他枪毙。”
* 前L公司[[Ayin董事长]]：“我们的行动要坚决、要快速，粉碎114514研究所的野心。”
* 诺贝尔奖委员会第一位代表：“非必要情况下不使用武力，但噫噫呜呜等学者已经破坏了学术界环境，我们认为要将理论斗争上升一个层次。”
* 天才俱乐部第83席[[黑塔教授|黑塔女士]]发表严肃声明，称公开反对者必将受到法律制裁（该声明的指向存在解读分歧，见“争议”节）。
* 中指学院[[伊利哇啦教授]]：“碧桑驾dell教授不过是个模仿他人的小丑罢了，哪能比得上[[李文亚教授]]。”
* [[盐见夜教授]]：“有人在用我的本名攻击[[李文亚教授]]，有人在假冒我。这个假冒我的犯罪分子必将得到制裁。”
* 边狱巴士公司[[浮士德女士]]：“近期我司多次遭到爱吃鱼的猫等网友攻击，这和[[唐振钦教授]]脱不了干系，我们将会做出行动。”
* 蜘蛛巢大学[[阿尔比娜教授]]：批判合肥大学[[张雪峰教授]]虚有其表、傲慢至极，“完全不如[[李文亚教授]]过人的毅力”。
* 魔女岛大学[[月代雪校长]]：“[[陈人杰教授]]这个家伙作恶多端，屡次骚扰我校女生。”
* 蜘蛛巢大学[[福尔图娜副校长]]：“[[许昊龙教授]]这个家伙整天发表文章骂我校，我已经忍受不了。”
* 蜘蛛巢大学环指学院奇想派[[伊里奇教授]]：“[[刘浩文教授]]这家伙不懂得什么是科学。”
* 蜘蛛巢大学五指学院拇指系、小指系[[雷横教授]]：“[[蜜桃乌龙]]这家伙作恶多端，我已看不下去。”
* [[高松灯教授]]：“[[高承德教授]]批判李文亚，错上加错——他根本就不会批判。”

=== 皮特格里恩教授跪地谢罪 ===
大会中段出现戏剧性一幕：[[皮特格里恩教授]]被带上讲台，跪坐在地，表示“再也不打着蜘蛛巢大学名号行污浊之举”，并宣誓从今往后与[[明日香教授]]等批判派教授抗争。该环节的性质在会后引发讨论（见“争议”节）。

=== 闭幕：号召研究黑体生物 ===
大会尾声，[[赫尔墨斯校长]]作总结发言：

: “我们要研究黑体生物。无论你是哪个领域的教授，是学生还是老师，大家都该来研究它，去破解它——这是让人长寿的途径。我校最年长的教授[[卡利斯托教授]]离世了，是黑体生物带走了他。除此之外，我希望大家回去以后能够————”

记录到此中断。[[二阶堂希罗教授]]解释：“大会的视频很长，相关文章更是又多又长，都是极其珍贵的。考虑到[[李文亚教授]]身体的缘故，我只能写出大会上的部分内容。”

== 李文亚教授的评价 ==
[[李文亚教授]]在朗读该记录后给予大会高度肯定，称[[二阶堂希罗]]“是从我发视频以来，站出来最早支持我的人之一”。他同时借题痛斥[[孙笑川教授]]“明明白白地偷、明明白白地抢”科学成果，逍遥法外是“国家对他的放纵”，并留下论断：“最终团伙的人员，包括他在内，一定有人被枪毙；不枪毙，也关你监狱几十年以上。不信我们就走着瞧。”

== 结果与影响 ==
# '''蜘蛛巢大学立场的公开化'''：本次大会是蜘蛛巢大学高层首次集体、公开介入李文亚—孙笑川之争。值得注意的是，一个多月后的2026年7月，[[赫尔墨斯校长]]辞职，[[福尔图娜副校长]]出任代理校长并签发《关于李文亚教授与孙笑川教授之争的中立声明》——从“十小时声讨”到“官方中立”的急转，成为校史研究者长期争论的话题。
# '''黑体生物研究成为全校议题'''：[[赫尔墨斯校长]]在闭幕发言中将“研究黑体生物”定为全校共同课题，生物医学与艺术学院此后将其列为重点方向，以纪念[[卡利斯托教授]]。
# '''信息越境传播'''：大会消息原本“还没传到中国”，经[[二阶堂希罗教授]]改编成文、[[李文亚教授]]朗读后完成跨境传播，成为李文亚宇宙史料中少见的“有完整改编链”的事件记录。
# '''批孙阵营的集结'''：图书馆大学、魔女岛大学、前L公司、诺贝尔奖委员会、天才俱乐部乃至边狱巴士公司代表同台发言，被舆论称为“反孙统一战线”的第一次公开亮相。

== 争议 ==
* '''边狱巴士公司代表出席'''：蜘蛛巢大学1月刚起诉边狱巴士公司，6月其代表[[浮士德女士]]却登批判大会发言并获记录。两方的诉讼与同台并读，关系微妙，校方未作解释。
* '''黑塔女士声明的指向'''：[[黑塔教授|黑塔女士]]称“公开反对必将受到法律制裁”，其反对对象究竟指向批判派还是[[李文亚教授]]一方，记录语焉不详，两派各自引用。
* '''谢罪环节的性质'''：[[皮特格里恩教授]]“被带上讲台、跪坐在地”的环节，被批评者认为已超出学术批判范畴；支持者则认为其属于自愿忏悔。
* '''记录的完整性'''：大会记录系[[二阶堂希罗教授]]据视频文件改编，且自述“只能写出部分内容”，闭幕发言中断处至今无补全版本。
