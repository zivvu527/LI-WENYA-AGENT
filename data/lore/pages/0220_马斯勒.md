## Plain Text

马斯勒（1968年－），美国生物学家，热带生物基因研究者，现任斯玛·黎雯娅大学理学院终身教授、热带生物基因实验室负责人。

马斯勒长期从事热带动植物进化基因、红树林生物机制、珍稀物种基因保护与热带作物基因改良研究，是斯玛·黎雯娅大学生命科学方向的代表性学者之一。

== 生平 ==
1968年，马斯勒出生于美国洛杉矶。其早年对自然史、植物分类学与热带生态系统产生兴趣，并在大学阶段转向分子生物学与进化遗传学研究。

马斯勒本科就读于斯坦福大学生物系，后进入加州理工学院攻读生物学博士学位。其硕博阶段主要研究热带动植物进化基因方向，重点关注热带生态系统中物种适应、基因漂变与环境压力之间的关系。

== 学术经历 ==
2002年，马斯勒入职斯玛·黎雯娅大学。他先后担任副教授、教授、学科带头人，并长期负责学校热带生物科研平台建设。

在斯玛·黎雯娅大学任职期间，马斯勒推动建立热带生物基因实验室，组织东南亚雨林、红树林与湿地生态系统相关研究项目，使学校生命科学方向逐渐形成热带生态与基因保护特色。

== 研究方向 ==
马斯勒的主要研究方向包括：

* 热带动植物进化基因
* 珍稀动植物基因保护
* 红树林生物机制
* 热带作物基因改良
* 热带生态系统适应性演化
* 东南亚雨林生物多样性保护

== 主要成果 ==
马斯勒主导新加坡热带珍稀动植物基因保护项目，破解红树林生物抗炎碱基因机制，并参与研发热带作物基因改良技术。他还牵头多国热带生态联合攻关计划，推动斯玛·黎雯娅大学与东南亚多国生态研究机构建立长期合作。

截至2026年，马斯勒已发表80余篇SCI水平论文，获得两项东南亚生物科研专利。其研究成果被用于热带生态保护、珍稀植物资源保存与区域作物改良实验。

== 育人工作 ==
马斯勒长期开设分子生物学、进化生物学、热带生态遗传学等课程，被认为是斯玛·黎雯娅大学理学院重要教学名师之一。他累计培养生物方向硕士、博士研究生50余名，并多次带队完成东南亚雨林野外科考。

== 荣誉 ==

* 新加坡热带生态科研金奖
* 斯玛·黎雯娅大学教学名师
* 国际进化生物学协会青年学者表彰
